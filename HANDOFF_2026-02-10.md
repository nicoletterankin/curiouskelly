## 2. Word Orb Batch Seeding Script (BLOCKED — API generation broken)

### What happened

The user provided a Python script to batch-seed ~2,207 words by hitting the Word Orb API. The script was pasted directly into PowerShell (line by line), which failed because PowerShell is not a Python interpreter.

I reconstructed the script from the terminal output, saved it as `C:\Users\user\v0-the-dl\batch.py`, and ran it.

### Issue 1: Wrong API URL (fixed)
The original script targeted `https://thedailylesson.com/api/word/{word}` — but there is **no `/api/word/` route** in the Next.js app. That URL returns the full HTML page. The correct API is the Cloudflare Worker:

```
https://word-orb-api.nicoletterankin.workers.dev/api/word/{word}
```

I updated the script and reran it.

### Issue 2: API generation is broken (BLOCKING)
**All 2,207 words failed.** Root cause:

- **Health check works:** `GET /api/health` → `{"status":"healthy","checks":{"kv":"ok","fb":"ok","key":"set","d1":"ok (345 words)"}}`
- **Cached words work:** Words already in D1 (like `sun`, `water`, `earth`, `light`, `time`, `love`, `the`, `science`, `music`) return 200 with full data
- **New word generation fails:** Any word NOT in D1 returns `HTTP 500: {"error":"Generation failed","word":"..."}`
- **Even "gravity" fails** despite being mentioned as pre-seeded — it may not actually be in D1

**Diagnosis:** The Cloudflare Worker's Claude API integration for on-demand word generation is broken. Possible causes:
1. Claude API key expired or quota exceeded
2. Worker environment variable misconfigured
3. Claude API endpoint/model changed
4. Rate limiting or billing issue on the AI provider side

## Architecture Reference

```
User clicks word in lesson
  → InteractiveText component captures click + position
  → WordOrb component fetches from Cloudflare Worker API
  → Worker checks D1 database (instant) → if miss, calls Claude API (2-5s)
  → Response cached permanently in D1
  → Floating pill renders near clicked word
```

**API Base:** `https://word-orb-api.nicoletterankin.workers.dev`
- `GET /api/health` — health check
- `GET /api/word/{word}` — word data (IPA, etymology, translations, tones)

**D1 Database:** 345 words currently cached and working.
