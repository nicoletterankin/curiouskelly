# Kelly Avatar Image Generation Prompts

**Purpose**: AI-generated images of Kelly at different ages to represent our age-adaptive learning approach  
**Note**: These are text-only prompts for Midjourney/DALL-E. Images will be replaced by 3D models in future releases.

---

## Generation Guidelines

### Universal Style Parameters
- Photorealistic quality, not illustrated/cartoon
- Warm, approachable facial expression  
- Educational/learning environment context
- Clean, professional lighting
- Diverse ethnicity representation
- 16:9 aspect ratio for web hero sections
- 1:1 square ratio for profile/testimonial cards

### Color Palette
- Primary: Indigo (#6366f1), Purple (#8b5cf6), Pink (#ec4899)
- Backgrounds: Soft gradients, bokeh effects, or clean white
- Clothing: Modern casual or smart-casual in brand colors

## Post-Generation Optimization

### Technical Requirements
- **Format**: WebP with JPEG fallback
- **Sizes needed**: 
  - Hero: 1920x1080px (16:9)
  - Profile: 800x800px (1:1)
  - Thumbnail: 400x400px (1:1)
  - Retina: 2x versions of all
- **Compression**: Optimize for web without quality loss
- **Alt text**: Descriptive for accessibility

### Quality Checklist
- [ ] Face clearly visible and well-lit
- [ ] Expression warm and approachable
- [ ] Background not distracting
- [ ] Clothing appropriate and on-brand
- [ ] Ethnicity representation feels authentic
- [ ] Age representation accurate
- [ ] Professional quality (not overly filtered)
- [ ] Passes brand color aesthetic

## Generation Workflow

1. **Generate Initial Set** (5 variations per age)
   - Run primary prompt with seed variations
   - Generate with different styles (--s 100, 250, 500)

2. **Review & Select**
   - Choose best 1-2 per age group
   - Check for consistency across ages
   - Verify brand alignment

3. **Refinement Round**
   - Regenerate selected options with minor prompt adjustments
   - A/B test with team
   - Final selection

4. **Optimization**
   - Export at required sizes
   - Convert to WebP
   - Create retina versions
   - Compress for web

5. **Deployment**
   - Upload to `/public/images/kelly/`
   - Update components to use new images
   - Test on staging
   - Deploy to production

## Budget Estimation

**Midjourney Subscription**: ~$30/month
- Fast generation: ~400 images/month
- Relaxed mode: Unlimited

**DALL-E 3 via API**: ~$0.04 per image (1024x1024)
- 20 generations = ~$0.80

**Recommendation**: Start with DALL-E 3 for quick iterations, move to Midjourney for final hero images if higher quality needed.

## Character Consistency Notes

Since we cannot upload reference images via API, maintain consistency through:
1. **Detailed descriptions** in every prompt
2. **Same seed values** when regenerating
3. **Consistent style parameters** (--s 250 --v 6)
4. **Brand color mentions** in every prompt
5. **Manual review** to ensure Kelly is recognizable across ages
