## Integration

1. Copy `images/brand/` → `public/images/brand/`
2. Copy `images/social/` → `public/images/social/`
3. Copy `images/expressions/` → `public/images/expressions/`
4. Copy `css/` → `public/css/`
5. Copy `manifest.json` → `public/`
6. Add contents of `snippets/head-tags.html` to all HTML `<head>` sections
