## ✅ QUALITY CRITERIA CHECKLIST

For each visual, validate:

### Academic Rigor
- [ ] **Scientifically accurate** (for science topics)
- [ ] **Age-appropriate complexity** (5-12 years)
- [ ] **Supports learning objective** clearly
- [ ] **Developmentally appropriate** concepts
- [ ] **Culturally sensitive** representations

### Visual Design
- [ ] **16:9 aspect ratio** (widescreen)
- [ ] **No text overlays** (visual-only per spec)
- [ ] **Clean, professional design**
- [ ] **Clear visual metaphors**
- [ ] **High resolution** (1344x768 minimum)

### Educational Value
- [ ] **Enhances understanding** (not decorative)
- [ ] **Memorable imagery** (aids retention)
- [ ] **Appropriate abstraction level**
- [ ] **Supports multiple learning styles**
- [ ] **Encourages curiosity**

### Safety & Appropriateness
- [ ] **No scary/disturbing imagery**
- [ ] **Inclusive representations**
- [ ] **Positive emotional tone**
- [ ] **No commercial/branded content**
- [ ] **COPPA compliant**

## 📝 QUALITY ISSUES TO FLAG

If you find any of these, we need to regenerate:

### Critical Issues (Block Production)
- ❌ Scientifically inaccurate information
- ❌ Inappropriate content for children
- ❌ Text overlays (violates spec)
- ❌ Low resolution/pixelated
- ❌ Wrong aspect ratio

### Medium Issues (Improve Before Scale)
- ⚠️ Unclear visual metaphors
- ⚠️ Too complex for target age
- ⚠️ Poor color choices
- ⚠️ Generic/stock-photo feel
- ⚠️ Doesn't match lesson topic

### Minor Issues (Nice to Fix)
- 💡 Could be more engaging
- 💡 Slight design inconsistencies
- 💡 Better metaphor exists
- 💡 Color palette could improve
