# Content Agent Base Knowledge

This folder contains all essential files for onboarding a content management agent to build lessons for Curious Kelly using Claude Code.

## 📋 Contents

1. **CONTENT_AGENT_ONBOARDING.md** - Main onboarding guide (read first!)
2. **CONTENT_AGENT_REQUIRED_FILES.md** - List of all required files
3. **lesson-template.json** - Starting template for new lessons
4. **lesson-authoring-guide.md** - Complete writing guide
5. **lesson-dna-schema.json** - JSON schema for validation
6. **validate-lesson.js** - Validation tool
7. **preview-lesson.js** - Preview tool
8. **generate-audio.js** - Audio generation tool
9. **package.json** - Node.js dependencies
10. **README.md** (this file) - Quick reference
11. **the-sun-dna.json** - Complete example lesson

## 🚀 Quick Start

1. Read `CONTENT_AGENT_ONBOARDING.md` first
2. Study `the-sun-dna.json` as a reference
3. Copy `lesson-template.json` to start new lessons
4. Use validation tools to check your work

## 📝 Usage

All files are self-contained in this folder. Upload this entire folder as base knowledge for your Claude skill.
