# Translation Guide for Curious Kelly Lessons
**Version:** 1.0  
**Date:** November 18, 2025

---

## Purpose

This guide ensures consistent, high-quality translations across all Curious Kelly lessons for Spanish (ES) and French (FR) audiences.

---

## Core Principles

### 1. **Age-Appropriate Language**
Each age variant requires different vocabulary complexity:

| Age Group | Language Complexity | Example (EN → ES → FR) |
|-----------|---------------------|----------------------|
| **2-5** | Very simple, concrete | "sun" → "sol" → "soleil" |
| **6-12** | Simple, beginning abstract | "energy source" → "fuente de energía" → "source d'énergie" |
| **13-17** | Moderate, more abstract | "nuclear fusion" → "fusión nuclear" → "fusion nucléaire" |
| **18-35** | Complex, technical | "thermonuclear reaction" → "reacción termonuclear" → "réaction thermonucléaire" |
| **36-60** | Sophisticated, nuanced | "stellar nucleosynthesis" → "nucleosíntesis estelar" → "nucléosynthèse stellaire" |
| **61-102** | Reflective, wisdom-oriented | "cosmic interconnection" → "interconexión cósmica" → "interconnexion cosmique" |

### 2. **Cultural Appropriateness**
- Use culturally neutral metaphors when possible
- Adapt idioms that don't translate literally
- Consider regional variations (Latin American Spanish vs. European Spanish)

### 3. **Consistency**
- Use the same translation for recurring terms within a lesson
- Follow glossary for technical terms
- Maintain Kelly's personality across languages

## Age-Specific Guidelines

### **Ages 2-5 (Playful Toddler Kelly)**

**Tone:** Enthusiastic, simple, wonder-filled

**Vocabulary:**
- Use 1-2 syllable words when possible
- Concrete nouns (sun, water, dog)
- Simple verbs (grow, shine, play)
- Avoid abstract concepts

**Spanish (ES):**
- Use diminutives: "solecito" (little sun), "perrito" (puppy)
- Keep sentences short (5-7 words max)
- Use present tense primarily

**French (FR):**
- Use "tu" form (informal)
- Simple present tense
- Avoid complex conjugations

**Example:**
```json
"en": "The sun is warm and bright!"
"es": "¡El sol es cálido y brillante!"
"fr": "Le soleil est chaud et brillant!"
```

---

### **Ages 6-12 (Curious Kid Kelly)**

**Tone:** Enthusiastic, educational, encouraging

**Vocabulary:**
- Mix simple and intermediate words
- Introduce basic scientific terms
- Use comparisons and analogies

**Spanish (ES):**
- Start introducing subjunctive mood in questions
- Use "tú" (informal you)
- Include some technical terms with simple explanations

**French (FR):**
- Continue "tu" form
- Introduce passé composé for past actions
- Use comparative structures

**Example:**
```json
"en": "The sun produces energy through nuclear fusion"
"es": "El sol produce energía mediante la fusión nuclear"
"fr": "Le soleil produit de l'énergie par fusion nucléaire"
```

---

### **Ages 13-17 (Enthusiastic Teen Kelly)**

**Tone:** Engaging, relevant, empowering

**Vocabulary:**
- Intermediate to advanced
- Full technical terminology
- Connect to teen interests and concerns

**Spanish (ES):**
- Use full subjunctive mood
- Include conditional tense
- More complex sentence structures

**French (FR):**
- Mix tu/vous depending on context
- Use all verb tenses as appropriate
- Include relative clauses

**Example:**
```json
"en": "Understanding solar physics helps us develop sustainable energy solutions"
"es": "Comprender la física solar nos ayuda a desarrollar soluciones energéticas sostenibles"
"fr": "Comprendre la physique solaire nous aide à développer des solutions énergétiques durables"
```

---

### **Ages 18-35 (Knowledgeable Adult Kelly)**

**Tone:** Professional, informative, practical

**Vocabulary:**
- Advanced, technical
- Professional terminology
- Real-world applications

**Spanish (ES):**
- Formal register when discussing technical topics
- Full range of tenses and moods
- Complex subordinate clauses

**French (FR):**
- Use "vous" for professional tone
- Sophisticated vocabulary
- Proper technical terminology

---

### **Ages 36-60 (Wise Mentor Kelly)**

**Tone:** Wise, experienced, balanced

**Vocabulary:**
- Sophisticated, nuanced
- Long-term perspective terms
- Wisdom-oriented language

---

### **Ages 61-102 (Reflective Elder Kelly)**

**Tone:** Reflective, legacy-focused, interconnected

**Vocabulary:**
- Philosophical, contemplative
- Life-span perspective
- Intergenerational language

## Cultural Adaptation Rules

### **Metaphor Translation**

**Rule:** If a metaphor doesn't work literally, find a culturally equivalent one.

**Example:**
```
EN: "The sun is like a giant light bulb in the sky"
ES: "El sol es como una bombilla gigante en el cielo" ✅ (works)
FR: "Le soleil est comme une ampoule géante dans le ciel" ✅ (works)
```

**But:**
```
EN: "It's raining cats and dogs"
ES: "Llueve a cántaros" (literally: "raining pitchers") ✅
FR: "Il pleut des cordes" (literally: "raining ropes") ✅
```

### **Units of Measurement**

**Rule:** Convert to metric for international audiences

```
EN: "The sun is 93 million miles away"
ES: "El sol está a 150 millones de kilómetros" ✅
FR: "Le soleil est à 150 millions de kilomètres" ✅
```

### **Examples and References**

**Rule:** Use universal or culturally neutral examples

**Good:**
- Nature examples (sun, water, trees)
- Universal experiences (family, friendship, growth)
- Widely known concepts

**Avoid:**
- US-specific references (baseball, Thanksgiving)
- Regional slang
- Brand names

## Kelly's Voice Consistency

### **Kelly's Character Traits (All Languages)**

1. **Enthusiastic:** Always energetic and excited about learning
2. **Curious:** Asks questions, encourages exploration
3. **Encouraging:** Positive reinforcement, celebrates effort
4. **Age-Adaptive:** Matches learner's developmental stage
5. **Wonder-Oriented:** Focuses on awe and amazement

### **Kelly's Language Patterns**

**Openings:**
```json
{
  "en": ["Ready to learn something amazing?", "Let's explore together!"],
  "es": ["¿Listo para aprender algo increíble?", "¡Exploremos juntos!"],
  "fr": ["Prêt à apprendre quelque chose d'incroyable?", "Explorons ensemble!"]
}
```

**Transitions:**
```json
{
  "en": ["But here's the cool part!", "Now watch this!"],
  "es": ["¡Pero aquí está la parte genial!", "¡Ahora mira esto!"],
  "fr": ["Mais voici le plus cool!", "Regarde maintenant!"]
}
```

**Encouragements:**
```json
{
  "en": ["You're doing great!", "Your brain is amazing!"],
  "es": ["¡Lo estás haciendo genial!", "¡Tu cerebro es increíble!"],
  "fr": ["Tu te débrouilles super bien!", "Ton cerveau est incroyable!"]
}
```

## Common Pitfalls to Avoid

### ❌ **DON'T:**
1. Use Google Translate without review
2. Translate idioms literally
3. Mix formal/informal address within age group
4. Use regional slang
5. Ignore age appropriateness
6. Copy-paste without context
7. Skip gender agreement (Spanish/French)
8. Forget accents (café vs cafe)

### ✅ **DO:**
1. Understand full context before translating
2. Adapt metaphors culturally
3. Stay consistent with glossary
4. Read translations aloud
5. Get native speaker review
6. Test with target age group
7. Maintain Kelly's voice
8. Preserve JSON structure
