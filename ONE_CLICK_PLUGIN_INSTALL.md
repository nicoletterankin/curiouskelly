# 🧩 How to Install the "Auto Setup" Plugin (Click-by-Click)

**Context:** You are in Unity. You need to install the "Magic Plugin" from Reallusion so Kelly looks real. You cannot find where to click.

---

## Step 1: Download the File (Outside Unity)
1.  Open your web browser (Chrome/Edge).
2.  Go to: [Reallusion Auto Setup Download](https://www.reallusion.com/auto-setup/unity/download.html)
3.  Scroll down to **"Auto Setup for Unity"**.
4.  Click **Download**.
    *   *(It might ask you to log in. Use your Reallusion account).*
5.  You will get a file named something like: `Unity_Auto_Setup_1.3.zip`.

---

## Step 2: Unzip the File
1.  Go to your **Downloads** folder.
2.  Right-click the `.zip` file (`CCIC_Auto_Setup_for_Unity.zip` or similar).
3.  Select **Extract All...** (or Unzip).
4.  Open the folder it created.
5.  You will see a folder named **`Plugins`**.

---

## Step 3: Drag & Drop (The Install)
1.  Open **Unity Hub** -> Open your project **`Kelly_Live_2025`**.
2.  Look at the bottom window in Unity called **Project**. It shows your folders (`Assets`, `Scenes`).
3.  Open your Windows File Explorer (where you unzipped the file).
4.  Find the folder named **`Plugins`** (inside the Auto Setup folder you unzipped).
5.  **CLICK AND DRAG** that `Plugins` folder directly into the Unity **Project** window (the bottom gray area).
6.  Release the mouse.

---

## Step 4: Wait & Verify
1.  Unity will show a "Hold on" loading bar for about 1-2 minutes.
2.  Once it finishes, look at the **Top Menu Bar** (File, Edit, Assets...).
3.  You should now see a new word: **`Tools`**.
4.  Click `Tools` -> You should see **`Character Creator & iClone Auto Setup`**.

**✅ Success!** The magic button is installed.

---
