```

```

Where:
- `{CDN_BASE}` = `https://tvjalxxsyryjphkforjv.supabase.co/storage/v1/object/public/kelly-templates`
- `{age}` = `kid`, `teen`, `adult` (no `/age/adult/`), `mature`, `elder`, `super_elder`
- `{archetype}` = `scientist`, `explorer`, `rebel`, `architect`, `diplomat`, `empath`, `macgyver`, `mystic`, `provider`, `storyteller`, `strategist`, `survivor`

**Exception:** For `adult` age, the URL is:
