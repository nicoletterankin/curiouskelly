## 🎯 Decision Framework

**When prioritizing tasks, ask:**
1. Does this generate revenue? (Priority 1)
2. Does this enable launch? (Priority 2)
3. Does this improve user experience? (Priority 3)
4. Does this scale the business? (Priority 4)

**If answer is "no" to all, defer it.**
