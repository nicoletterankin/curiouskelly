## 🔗 DOWNLOAD LINKS (Zero Trust Implementation)

### Smart Link System
All download links use a zero-trust verification system:

```javascript
APP_STORE_LINKS = {
  ios: { live: false, url: '...', fallback: '...' },
  android: { live: false, url: '...', fallback: '...' },
  // etc.
}
```

**How It Works**:
1. User clicks download button
2. System checks if app is live (`live: true/false`)
3. If live → Opens app store
4. If not live → Shows "Launching Dec 17" message
5. Offers email notification signup
6. Provides PWA fallback

**Benefits**:
- ✅ No broken links ever
- ✅ Clear communication
- ✅ Graceful fallbacks
- ✅ Email waitlist collection
- ✅ Easy to update (change `live: true`)
