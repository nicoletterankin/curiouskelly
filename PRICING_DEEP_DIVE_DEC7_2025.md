# CONVERSION FUNNEL OPTIMIZATION

## Price Presentation Order

**Wrong Way:**
```
Monthly: $7.99  ← User sees this first, anchors low
Annual: $49.99
```

**Right Way:**
```
Annual: $49.99/yr ($4.17/mo) ⭐ BEST VALUE  ← Default selection
Monthly: $7.99/mo
```

### Why Annual-First Works:
1. **Anchors higher** — $49.99 feels like the "real" price
2. **Shows savings** — $4.17/mo vs. $7.99/mo is compelling
3. **Default effect** — Pre-selected options convert higher
4. **Cash flow** — Front-loads revenue
