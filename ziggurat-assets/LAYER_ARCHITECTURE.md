# The Ziggurat — 7 Layer Architecture

## Overview

The Ziggurat transforms the Chet Holifield Federal Building into a 7-layer monument to human curiosity. Each layer serves a distinct purpose, from the permanent Foundation holding every human's place to the eternal Beacon at the Crown.

```
┌─────────────────────────────────────────┐
│  LAYER 7: THE CROWN                     │  ← White beacon, visible for miles
│  ═══════════════════════════════════    │     Static / Eternal
├─────────────────────────────────────────┤
│  LAYER 6: THE CALENDAR                  │  ← 365 rainbow segments
│  ═════════════════════════════════════  │     Today glows brightest
├─────────────────────────────────────────┤
│  LAYER 5: TODAY'S LESSON                │  ← Category color (magenta = Culture)
│  ══════════════════════════════════════ │     Changes daily at midnight
├─────────────────────────────────────────┤
│  LAYER 4: THE WONDER HALL               │  ← Gold with scrolling stars
│  ═══════════════════════════════════════│     Achievements celebrated
├─────────────────────────────────────────┤
│  LAYER 3: THE PULSE                     │  ← Green, pulsing heartbeat
│  ════════════════════════════════════════     Real-time learner activity
├─────────────────────────────────────────┤
│  LAYER 2: THE JOURNEY                   │  ← Cyan wave animation
│  ═════════════════════════════════════════     Collective progress
├─────────────────────────────────────────┤
│  LAYER 1: THE FOUNDATION                │  ← Orange, pixelated "people"
│  ══════════════════════════════════════════     8 billion permanent places
└─────────────────────────────────────────┘
```

## Layer Details

### Layer 1: The Foundation
**"8 Billion Learners"**

- **Color:** Warm amber/orange (#e85d04)
- **Update:** PERMANENT (display rotates, registry eternal)
- **Linear Feet:** 1,580 ft
- **Visual:** Pixelated pattern representing individual humans

Every person who ever lived, lives now, or will live has a permanent coordinate on this layer. The display rotates through active learners, but the DATABASE holds everyone. Your place exists whether you interact with it or not.

**Coordinate Format:** `ZIG-1-NW-047291`

---

### Layer 2: The Journey
**"Learning Progress"**

- **Color:** Cyan (#00d4ff)
- **Update:** Weekly
- **Linear Feet:** 1,580 ft
- **Visual:** Traveling wave animation

Shows collective progress across the global community. The "wave of curiosity" travels across the layer, representing learning activity moving across time zones as Earth rotates.

---

### Layer 3: The Pulse
**"Live Activity"**

- **Color:** Green (#22c55e)
- **Update:** Real-time (seconds)
- **Linear Feet:** 1,310 ft
- **Visual:** Pulsing heartbeat with activity segments

The real-time heartbeat of the learning community:
- "4,729 people learning RIGHT NOW"
- Names scrolling as people complete lessons
- Geographic indicators of active cities

Pulses every 3 seconds with data refresh.

---

### Layer 4: The Wonder Hall
**"Achievements"**

- **Color:** Gold (#fbbf24)
- **Update:** Daily
- **Linear Feet:** 1,060 ft
- **Visual:** Golden glow with scrolling celebration "stars"

Public celebration of accomplishments:
- 7-day streak: 1 hour spotlight
- 30-day streak: 4 hour spotlight
- 100-day streak: 24 hour spotlight
- 365-day completion: 1 week spotlight + permanent registry

---

### Layer 5: Today's Lesson
**"The Daily Topic"**

- **Color:** Category-based (see color system below)
- **Update:** Daily (midnight local time)
- **Linear Feet:** 820 ft
- **Visual:** Solid category color

Showcases today's learning topic. For Day 24 "Why Humans Tell Stories" (Category: Culture), the layer glows magenta (#c026d3).

### Layer 6: The Calendar
**"365 Days of Wonder"**

- **Color:** Rainbow spectrum
- **Update:** Annual (lessons evolve with feedback)
- **Linear Feet:** 580 ft
- **Visual:** 365 segments, each a different hue

The entire year's curriculum visible at once:
- January lessons on the left
- December lessons on the right
- Today's lesson (Day 24) glows brightest
- Past lessons subtly dimmed
- Future lessons await

---

### Layer 7: The Crown
**"The Universal Truth"**

- **Color:** Pure white (#ffffff)
- **Update:** Static (eternal)
- **Linear Feet:** 380 ft
- **Visual:** Brilliant white beacon

The eternal signal. Always on, always the same. Visible for miles. The "North Star" of learning. No content needed—just presence.

**Recommended Mode:** Pure beacon (simplest, most iconic).

## Technical Specifications

### Physical Installation

| Specification | Value |
|---------------|-------|
| Total Linear Feet | ~6,360 ft |
| Pixel Pitch | 16mm (outdoor) |
| Estimated Pixels | ~11.6 million |
| Panel Height | ~2 ft per layer |
| Weather Rating | IP65 |
| Control Protocol | DMX / Art-Net |

### Rendering Pipeline

1. Base Photo (aerial.jpg)
2. Night Grading (multiply + overlay composites)
3. Multi-pass Bloom (5-6 passes, 60px→10px blur)
4. Core LED Gradient (vertical brightness variation)
5. White-hot Center (overexposed stroke)
6. Surface Spill (downward light bounce)
7. Sky Glow (atmospheric scatter above building)
8. Vignette + Film Grain (cinematic finish)

1. **No one is removed from Layer 1.** Ever.
2. **No advertising.** Ever.
