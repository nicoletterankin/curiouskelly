> **Status:** Production Ready

## Overview

Kelly's Agentic Email System autonomously handles all emails to hello@curiouskelly.com:

- **Auto-responds** to support and feedback emails immediately
- **Drafts responses** for enterprise, press, and billing (awaiting approval)
- **Escalates** critical items to nicoletterankin@gmail.com
- **Learns** from patterns to improve over time

### Architecture

```
Gmail (hello@curiouskelly.com)
    ↓ Auto-forward
Resend Inbound (webhook)
    ↓
/api/email/inbound.ts
    ↓
Email Classifier (Claude AI)
    ↓
┌─────────────────────────────────────┐
│ Category-Based Routing              │
├─────────────────────────────────────┤
│ support/feedback → Auto-Respond     │
│ enterprise/press → Draft Queue      │
│ billing/partner  → Draft + Escalate │
│ angry/legal      → Immediate Escalate│
└─────────────────────────────────────┘
    ↓
Supabase (email_threads, email_messages, email_actions)
    ↓
Admin Dashboard (/admin/email-inbox.html)
```

## Setup Instructions

### Step 1: Run Database Migration

```bash
# In Supabase SQL Editor, run:
# supabase/migrations/20251217_agentic_email_system.sql
```

This creates:
- `email_threads` - Main thread tracking
- `email_messages` - Individual messages
- `email_actions` - Audit trail
- `email_templates` - Reusable responses
- `email_escalation_rules` - Escalation configuration

### Step 2: Configure Environment Variables

Add to Vercel:

| Variable | Value | Required |
|----------|-------|----------|
| `RESEND_API_KEY` | `re_xxx...` | ✅ Yes |
| `ANT_API_KEY` | Anthropic API key | ✅ Yes |
| `ESCALATION_EMAIL` | `nicoletterankin@gmail.com` | ✅ Yes |
| `RESEND_INBOUND_WEBHOOK_SECRET` | Generated by Resend | Optional |

### Step 3: Configure Resend Inbound

1. Go to [Resend Dashboard](https://resend.com/domains)
2. Select your domain (curiouskelly.com)
3. Click **Inbound** tab
4. Enable inbound emails
5. Set webhook URL: `https://www.curiouskelly.com/api/email/inbound`
6. Copy the webhook secret (if provided)

### Step 4: Configure Gmail Forwarding

1. Open Gmail for hello@curiouskelly.com
2. Go to **Settings** → **Forwarding and POP/IMAP**
3. Click **Add a forwarding address**
4. Enter: `inbound@mail.curiouskelly.com` (or your Resend inbound address)
5. Verify the forwarding address
6. Select: **Forward a copy of incoming mail to...**
7. Keep: **Keep Gmail's copy in the Inbox**

**Important:** Gmail will keep a copy, allowing you to see all emails even if the automation fails.

### Step 5: Add Cron Jobs to vercel.json

```json
{
  "crons": [
    {
      "path": "/api/cron/daily-lesson",
      "schedule": "0 12 * * *"
    },
    {
      "path": "/api/cron/email-digest",
      "schedule": "0 13 * * *"
    }
  ]
}
```

The email digest runs at 8am EST (1pm UTC) daily.

## Escalation Rules

### Always Escalate:
- Any mention of: `refund`, `lawyer`, `legal`, `lawsuit`, `attorney`
- Sentiment classified as `angry`
- Enterprise deals (any school/business inquiry)
- Press/media from recognized outlets
- Billing disputes or cancellation requests with frustration

### Escalation Flow:
1. Email is classified with escalation triggers
2. Draft response is generated
3. Immediate notification sent to nicoletterankin@gmail.com
4. Thread marked as `escalated` in database
5. Appears in Admin Dashboard with high priority

## API Endpoints

### POST /api/email/inbound
Receives Resend webhook for incoming emails.

### GET /api/email/threads
List threads with filtering.

```bash
# All threads needing action
curl "https://www.curiouskelly.com/api/email/threads?status=needs_action"

# Single thread with messages
curl "https://www.curiouskelly.com/api/email/threads?id=uuid"
```

### POST /api/email/approve
Approve a draft and send it.

```bash
curl -X POST "https://www.curiouskelly.com/api/email/approve" \
  -H "Content-Type: application/json" \
  -d '{
    "threadId": "uuid",
    "editedSubject": "Optional new subject",
    "editedBody": "Optional edited body"
  }'
```

### POST /api/email/reply
Send a custom reply.

```bash
curl -X POST "https://www.curiouskelly.com/api/email/reply" \
  -H "Content-Type: application/json" \
  -d '{
    "threadId": "uuid",
    "subject": "Re: Original Subject",
    "body": "Your custom response..."
  }'
```

## Kelly's Voice Guidelines

Every response follows these principles:

### Do:
- Be warm, curious, never corporate
- Use first person ("I" not "we")
- Acknowledge their specific situation
- Provide genuinely helpful information
- End with "Stay curious" or similar
- Include unexpected delight (fun facts, encouragement)
- Use emojis sparingly but meaningfully

### Don't:
- Use corporate language ("unfortunately", "as per policy")
- Be pushy or sales-y
- Sound robotic or template-y
- Use excessive exclamation marks
- Forget to personalize

### Example Response:

```
Hi Alex!

I'm so sorry you're locked out — that's always frustrating! 
Let me help you get back to learning.

Here's your password reset link: [link]

💡 Fun fact: The average person forgets 3 passwords per month. 
You're in very good company!

Stay curious,
Kelly ✨
```

## Troubleshooting

### Emails Not Arriving
1. Check Gmail forwarding is active
2. Verify Resend inbound is configured
3. Check Vercel function logs for errors
4. Ensure webhook URL is correct

### AI Classification Failing
1. Check `ANT_API_KEY` is set in Vercel
2. Verify API key is valid
3. Check Claude API rate limits
4. Fallback will save as draft requiring review

### Escalations Not Sending
1. Check `ESCALATION_EMAIL` is set
2. Verify `RESEND_API_KEY` works
3. Check spam folder in recipient inbox

### Admin Dashboard Empty
1. Ensure database migration ran
2. Check Supabase connection
3. Verify service role key is set
