# 📬 Gmail Setup for hello@curiouskelly.com

## Step-by-Step Setup (15 minutes)

---

## 1. Verify Email is Working

First, send a test email to yourself:
1. Go to Gmail
2. Compose → To: your personal email
3. From: Should show hello@curiouskelly.com
4. Send and confirm you receive it

**If it's not showing the right "From" address:**
- Settings → See all settings → Accounts and Import
- "Send mail as:" → Add hello@curiouskelly.com
- Follow verification steps

---

## 2. Create Your Signature

**Settings → See all settings → General → Signature**

```
✨ Stay curious,
Kelly

—
Curious Kelly | Learn something new every day
curiouskelly.com
```

**Check boxes:**
- ✓ Insert signature before quoted text in replies
- ✓ Use for new emails
- ✓ Use for replies/forwards

---

## 3. Enable Templates (Canned Responses)

**Settings → See all settings → Advanced**
- Templates: **Enable**
- Save Changes

**To save a template:**
1. Compose a new email
2. Write your template
3. Click ⋮ (three dots) → Templates → Save draft as template

**To use a template:**
1. Compose new email
2. Click ⋮ → Templates → Select template
3. **IMPORTANT:** Personalize before sending!

---

## 4. Create Labels for Organization

**Left sidebar → Scroll down → Create new label**

Create these labels:

| Label | Purpose |
|-------|---------|
| 🔴 URGENT | Billing issues, site down |
| 🟡 SUPPORT | General help requests |
| 🟢 FAMILY | Parent/child account inquiries |
| 🔵 ENTERPRISE | Schools, businesses |
| 💜 PRESS | Media, interviews |
| ⭐ VIP | Lifetime members, influencers |
| 💡 FEEDBACK | Product suggestions |
| 💌 FAN MAIL | Positive testimonials |
| 📦 ARCHIVED | Resolved items |

**To color-code:**
Right-click label → Label color → Choose color

---

## 5. Set Up Filters (Auto-Label)

**Settings → See all settings → Filters and Blocked Addresses → Create a new filter**

### Filter 1: Family Inquiries
- Has the words: `child OR kid OR son OR daughter OR parent OR under 13 OR family`
- Apply label: 🟢 FAMILY

### Filter 2: Enterprise
- Has the words: `school OR teacher OR classroom OR enterprise OR organization OR business`
- Apply label: 🔵 ENTERPRISE

### Filter 3: Press
- Has the words: `press OR journalist OR media OR interview OR article OR publication`
- Apply label: 💜 PRESS

### Filter 4: Billing
- Has the words: `refund OR charge OR billing OR cancel OR subscription OR payment`
- Apply label: 🔴 URGENT

---

## 6. Set Up Vacation Responder (Optional)

For after-hours or weekends:

**Settings → See all settings → General → Vacation responder**

```
Subject: Kelly got your message! ✨

Hi there!

Thanks for reaching out! I'm currently away from my desk (probably learning something new 📚), but I wanted you to know your message landed safely.

I'll get back to you within 24 hours - usually much sooner!

In the meantime, have you checked out curiouskelly.com/help? I put answers to the most common questions there!

Stay curious,
Kelly
```

---

## 7. Multiple Inbox View (Power User)

See different categories at once:

**Settings → See all settings → Inbox → Inbox type: Multiple Inboxes**

Section 1: `label:URGENT`
Section 2: `label:SUPPORT`
Section 3: `is:starred`

---

## 8. Keyboard Shortcuts (Speed Up)

**Settings → See all settings → General → Keyboard shortcuts: ON**

Essential shortcuts:
- `c` - Compose new email
- `r` - Reply
- `a` - Reply all
- `#` - Delete
- `e` - Archive
- `l` - Apply label
- `s` - Star/unstar
- `/` - Search

## Troubleshooting

**"Send As" not showing hello@curiouskelly.com:**
- Need to verify domain ownership
- Check DNS settings for email
- Contact domain provider

**Emails going to spam:**
- Add SPF/DKIM records to domain
- Warm up the email address gradually
- Avoid spam trigger words

**Templates not saving:**
- Make sure Advanced settings has Templates enabled
- Try logging out and back in
