## 🔀 TWO GENERATION ROUTES

### Route A: CC5 Renders (Manual)
- Use Character Creator 5 / iClone
- Render each pose manually
- Higher quality, more control
- ~10-12 hours of work

### Route B: LoRA Generation (Automated)
- Use `scripts/kelly-lora-asset-factory.ts`
- Generates via Replicate + trained Kelly LoRA
- Faster, programmatic, batch processing
- Run: `npx tsx scripts/kelly-lora-asset-factory.ts`

## 📂 RENDER OUTPUT FOLDER

Save all CC5 renders to:
```
projects/Kelly/CC5/final-models/renders/
```

Then run the deployment script to copy to production locations.
