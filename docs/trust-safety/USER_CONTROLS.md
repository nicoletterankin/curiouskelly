# USER CONTROLS FOR SIMULATED CONTENT

> *"Your learning, your way. Full control, always."*

---

## Control Philosophy

Users must have **meaningful, accessible, and respected** control over simulated social content. This is non-negotiable.

---

## The Master Toggle

### Location
Settings → Social Experience → Simulated Content

### Behavior

```
┌─────────────────────────────────────────────────┐
│  SIMULATED SOCIAL CONTENT                       │
│  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━  │
│                                                 │
│  Kelly shows AI-generated comments and          │
│  reactions from simulated learners to create    │
│  a supportive learning environment.             │
│                                                 │
│  All simulated content is marked with ✨        │
│                                                 │
│  ┌─────────────────────────────────────────┐   │
│  │  Show simulated content          [ON]   │   │
│  └─────────────────────────────────────────┘   │
│                                                 │
│  [Learn why we do this]                         │
│                                                 │
└─────────────────────────────────────────────────┘
```

### When OFF:
- All simulated social content is hidden
- Learning experience continues normally
- Kelly still teaches, just without simulated peer interactions
- User can re-enable at any time

## Onboarding Disclosure

### First Launch

When a user first encounters simulated content, they see this one-time explanation:

```
┌─────────────────────────────────────────────────┐
│                                                 │
│                      ✨                         │
│                                                 │
│          LEARNING IS SOCIAL                     │
│                                                 │
│  Humans learn best with others. That's why     │
│  Kelly shows comments from simulated           │
│  learners—to make you feel less alone.         │
│                                                 │
│  These comments are AI-generated and           │
│  marked with ✨ so you always know.            │
│                                                 │
│  You're in full control:                       │
│                                                 │
│  • Turn them off anytime in Settings           │
│  • Tap ✨ to learn more about any comment      │
│  • Real community features coming soon         │
│                                                 │
│        [Got it, show me simulated content]     │
│                                                 │
│        [No thanks, I prefer solo learning]     │
│                                                 │
└─────────────────────────────────────────────────┘
```

### Choice is Respected

- If user chooses "solo learning," simulated content is OFF by default
- Preference is stored and synced across devices
- User can change anytime in Settings

## Accessibility

### Screen Reader Support

```html
<div class="simulated-content" 
     role="complementary"
     aria-label="Simulated learner comment">
  <span class="simulated-indicator" aria-hidden="true">✨</span>
  <span class="sr-only">Simulated learner named Maya says:</span>
  <p>"I love how this connects to what we learned yesterday!"</p>
  <cite>— Maya</cite>
</div>
```

### Keyboard Navigation

- Tab to simulated content shows focus ring
- Enter/Space opens disclosure tooltip
- Escape closes tooltip
- Settings toggle is fully keyboard accessible

### Reduced Motion

If user prefers reduced motion:
- No animation on ✨ icon
- Tooltip appears instantly (no fade)
- No hover effects

## API for Preferences

```javascript
// Get current preferences
const prefs = await kelly.getSimulatedContentPreferences();
// Returns: { enabled: true, types: {...}, disclosure: 'standard' }

// Update preferences
await kelly.setSimulatedContentPreferences({
  enabled: true,
  types: {
    peerComments: true,
    ageResponses: false,
    questions: true,
    milestones: true,
    discussions: false
  },
  disclosure: 'enhanced'
});

// Quick toggle
await kelly.toggleSimulatedContent(false); // Turn off
await kelly.toggleSimulatedContent(true);  // Turn on
```

## What Happens When Simulated Content is OFF

### Learning continues normally:
- Kelly still teaches
- Lessons still work
- Progress still tracks
- Streaks still count

### What's removed:
- Peer learner comments
- Age perspective responses  
- "Other learners asked" prompts
- Simulated discussions

### What stays:
- Kelly's direct teaching
- Questions Kelly asks YOU
- Your own progress data
- Real community (when available)
