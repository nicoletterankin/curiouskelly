## Usage Notes

1. Always customize bracketed sections with specific information
2. Keep founder anonymous—use "the company" or "the founder" language
3. Include concrete metrics whenever possible
4. Only use hello@curiouskelly.com (authorized email)
5. Add judge quotes when provided by award organization
6. Include impact stories that humanize the achievement
