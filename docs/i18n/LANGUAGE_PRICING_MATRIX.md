## 💰 SPONSORSHIP MODEL

### Option 1: Stripe Checkout (Direct Payment)
```
User → Stripe → Language Fund → Translation Queue → Published
```

**Example:**
- Maria wants to sponsor German: $30 one-time
- Payment processed via Stripe
- German added to priority queue
- We run translation with our GPT-4 credits
- Maria credited as sponsor

### Option 2: BYOK Credit Donation
```
User → Provides API Key → Daily Translation Runs → Commons
```

**Example:**
- João has Google Cloud with $200/month free tier
- Provides key to Lesson of the Day
- System uses his daily credits for Portuguese translations
- All translations saved to commons
- João gets personalized emails in Portuguese
- Everyone gets access to Portuguese lessons

### Option 3: Hybrid Sponsorship
```
User → Partial $$ + Partial BYOK → Faster Completion
```

## 📱 OFFLINE DOWNLOAD MODEL

Each completed language creates:

```
language-pack-{code}.zip
├── lessons/
│   ├── day-1.json (full i18n)
│   ├── day-2.json
│   └── ... (365 files)
├── audio/ (if generated)
│   ├── day-1-hook.mp3
│   └── ...
├── visuals/ (shared)
│   ├── day-1-hook-scene.png
│   └── ...
└── manifest.json
    ├── version
    ├── language
    ├── sponsors
    └── contributors
```

**Download sizes (estimated):**
- JSON only: ~15 MB
- With audio: ~500 MB
- With visuals: ~2 GB
