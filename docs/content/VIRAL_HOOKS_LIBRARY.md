## 🔧 HOOK FORMULAS TO MIX & MATCH

### Formula 1: The Contradiction
```
"[Thing everyone does] is actually [opposite of expected result]."

Examples:
- "Taking notes is actually making you forget."
- "Trying to relax is actually stressing you out."
- "Thinking positive is actually making things harder."
```

### Formula 2: The Insider Secret
```
"[Authority figure/group] all do [unexpected thing]. Here's why."

Examples:
- "CEOs all read the same 3 books. Here's what they are."
- "World-class athletes skip breakfast. Here's the science."
- "Surgeons listen to music during operations. Here's why it works."
```

### Formula 3: The Before/After
```
"I used to [common mistake]. Then I learned [insight]."

Examples:
- "I used to work 80 hours a week. Then I learned about deep work."
- "I used to forget everything I read. Then I found the Feynman Technique."
- "I used to think I was stupid. Then I learned about learning styles."
```

### Formula 4: The Specific Number
```
"[Specific number] [things] that [promise]."

Examples:
- "3 words that make you more persuasive."
- "7 seconds to change someone's mind."
- "21 days to build any habit. (Actually, it's not 21.)"
```

### Formula 5: The Time-Bound Promise
```
"How to [result] in [surprisingly short time]."

Examples:
- "How to fall asleep in 120 seconds."
- "How to read a 300-page book in a weekend."
- "How to learn any language in 6 months."
```

### Formula 6: The Pattern Breaker
```
"Stop [common behavior]. Do [counterintuitive thing] instead."

Examples:
- "Stop taking notes. Start making connections."
- "Stop setting goals. Start building systems."
- "Stop reading more. Start reading twice."
```

## 🎯 HOOK TESTING FRAMEWORK

### Test Variables:
1. **Opening Word** (You/I/What/Why/How)
2. **Emotion** (Surprise/Curiosity/Fear/Wonder)
3. **Specificity** (Vague vs. Precise numbers)
4. **Promise** (Implicit vs. Explicit)

### A/B Test Ideas:
- "Your brain..." vs. "The brain..."
- Question format vs. Statement format
- Number-first vs. Concept-first
- First person vs. Second person

### Track:
- Hook-to-end retention (video)
- Open rate (email)
- Reply rate (social)
- Save rate (Instagram)
