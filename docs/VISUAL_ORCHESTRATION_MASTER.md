## 📱 THE VISION: Interactive TikTok Learning

Think of each lesson as a **highly choreographed TikTok** with learning baked in:
- **Hook** (5-8 sec): Visual punch + curiosity spike
- **Q1-Q3** (8-12 sec each): Facts with interactive choices (IMAGES!)
- **Wisdom** (5-8 sec): Emotional close + universal truth

**TOTAL:** 45-60 seconds of pure, visual, snackable education.

## 🖼️ OPTION A/B IMAGE SPECIFICATIONS

### The Problem We're Solving:
Currently options are TEXT ONLY:
```
Option A: "Sound travels faster in water"
Option B: "Sound travels slower in water"
```

### The Visual Solution:
Options become IMAGES:

```
OPTION A IMAGE:
┌─────────────────────┐
│  🐋                  │
│ Whale with sound    │
│ waves spreading     │
│ through water       │
│                     │
│ "Through Water!" ✓  │
└─────────────────────┘

OPTION B IMAGE:
┌─────────────────────┐
│  🔊                  │
│ Speaker in air      │
│ with shorter        │
│ sound waves         │
│                     │
│ "Through Air?"      │
└─────────────────────┘
```

### Option Card Image Prompt Template:

```
# OPTION A/B IMAGE TEMPLATE

Generate a 512x512 educational choice card for "[TOPIC]".

OPTION A (usually correct/best):
- Visual: [SPECIFIC VISUAL REPRESENTATION]
- Icon overlay: [EMOJI or ICON]
- Text: "[SHORT 2-3 WORD LABEL]"
- Border: Subtle green glow (correct answer indicator)
- Style: Clean, bold, instantly readable

OPTION B (interesting alternative):
- Visual: [SPECIFIC VISUAL REPRESENTATION]  
- Icon overlay: [EMOJI or ICON]
- Text: "[SHORT 2-3 WORD LABEL]"
- Border: Neutral/subtle
- Style: Clean, bold, instantly readable

Both should be photorealistic, 512x512, with clear contrast,
large enough visual to be tappable on mobile, educational infographic style.
```

## 📐 INFOGRAPHIC PROMPT TEMPLATES

### Template 1: SPLIT-SCENE COMPARISON (Day 5 Style)

```prompt
Educational infographic: Split-scene comparison showing [CONCEPT].

LEFT SIDE: [SCENE A DESCRIPTION]
- Key visual: [SUBJECT]
- Effect visualization: [HOW CONCEPT MANIFESTS]
- Label: "[TEXT LABEL]"
- Data point: "[STATISTIC IF APPLICABLE]"

RIGHT SIDE: [SCENE B DESCRIPTION]
- Key visual: [SUBJECT]
- Effect visualization: [HOW CONCEPT MANIFESTS]
- Label: "[TEXT LABEL]"
- Human element: [RELATABLE PERSON/POV]

HEADER TEXT: "[MAIN EDUCATIONAL TAKEAWAY]"

Style: Photorealistic cinematic, 8K resolution, educational diagram 
aesthetic, smooth color transition between scenes, clear typography, 
no clutter.
```

### Template 2: BEFORE/AFTER TRANSFORMATION

```prompt
Educational infographic showing transformation: [CONCEPT].

BEFORE STATE (left/top):
- Scene: [INITIAL STATE]
- Visual indicator: [WHAT TO LOOK FOR]
- Label: "Before: [STATE]"

AFTER STATE (right/bottom):
- Scene: [TRANSFORMED STATE]
- Visual indicator: [WHAT CHANGED]
- Label: "After: [STATE]"

Arrow or timeline connecting the two states.
Clear cause-and-effect visualization.
Style: Documentary photography, clean educational overlay.
```

### Template 3: PROCESS/CYCLE DIAGRAM

```prompt
Educational infographic: [PROCESS NAME] cycle/steps.

Step 1: [VISUAL] → Label: "[STEP]"
Step 2: [VISUAL] → Label: "[STEP]"
Step 3: [VISUAL] → Label: "[STEP]"
(repeat as needed)

Circular or linear flow with arrows.
Each step has clear icon and short text.
Background: [CONTEXTUAL ENVIRONMENT]
Style: Modern infographic, clean vectors on photorealistic background.
```

### Template 4: SCALE/COMPARISON

```prompt
Educational infographic: Size/scale comparison for [CONCEPT].

Objects arranged from smallest to largest (or vice versa):
- [OBJECT 1]: [SIZE/QUANTITY]
- [OBJECT 2]: [SIZE/QUANTITY]
- [OBJECT 3]: [SIZE/QUANTITY]

Human figure for scale reference.
Clear size labels and relationship indicators.
Style: Clean white background, dramatic lighting on objects, 
educational measurement aesthetic.
```

### Template 5: ANATOMY/CROSS-SECTION

```prompt
Educational infographic: Cross-section view of [SUBJECT].

Main visual: [SUBJECT] cut away to reveal interior
Labeled parts:
- [PART 1]: "[FUNCTION]"
- [PART 2]: "[FUNCTION]"
- [PART 3]: "[FUNCTION]"

Clean label lines connecting to parts.
Background: [CONTEXTUAL or NEUTRAL]
Style: Scientific illustration meets cinematic photography,
detailed but not overwhelming, clear visual hierarchy.
```
