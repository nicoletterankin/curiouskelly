## 🎬 VIDEO CODEC SPECIFICATIONS

```
Container: MP4
Video Codec: H.264 (AVC)
Profile: High
Level: 4.1
Pixel Format: yuv420p
Frame Rate: 30fps
Resolution: 1920×1080

Audio Codec: AAC
Sample Rate: 44100 Hz
Channels: Stereo
Bitrate: 128kbps

CRF: 23 (balance quality/size)
Preset: slow (better compression)
```

### FFmpeg Command:
```bash
ffmpeg -i input.mov \
  -c:v libx264 -crf 23 -preset slow \
  -c:a aac -b:a 128k \
  -movflags +faststart \
  output.mp4
```
