### Directory: `tools/social-media-automation/`

#### 1. **Post Scheduler** (`post_scheduler.py`)
- **What it does:** Schedules and publishes posts via Buffer API
- **Use it for:** Automating weekly posting, batch scheduling
- **Features:**
  - Multi-platform scheduling
  - Content calendar integration
  - Analytics reporting
  - Direct Twitter posting

**Usage:**
```bash
python post_scheduler.py
```

---

#### 2. **Content Generator** (`content_generator.py`)
- **What it does:** Uses AI (OpenAI GPT) to generate posts
- **Use it for:** Bulk content creation, writer's block solutions
- **Features:**
  - Generate tweets, captions, threads, video scripts
  - Kelly's brand voice built-in
  - Tone adaptation (neutral, fun, wisdom)
  - Batch generation (week of content)

**Usage:**
```bash
python content_generator.py
```

**Generate one post:**
```python
from content_generator import ContentGenerator
generator = ContentGenerator()
tweet = generator.generate_twitter_post("why the sky is blue", tone="fun")
```

---

#### 3. **Analytics Tracker** (`analytics_tracker.py`)

- **Use it for:** Weekly reports, performance analysis
- **Features:**

  - Engagement rate calculations
  - CSV export

**Usage:**

## ✅ Common Workflows

### Weekly Content Creation Workflow

**Monday morning (2 hours):**
1. Open `CONTENT_CALENDAR_SYSTEM.md`
2. Review this week's themes
3. Run `python content_generator.py --generate-week`
4. Customize AI-generated posts
5. Add visuals (Canva templates)
6. Schedule via `python post_scheduler.py`

**Daily (30 min):**
1. Check scheduled posts published
2. Respond to comments/mentions
3. Post spontaneous Stories
4. Discord community check-in

**Friday end-of-week (1 hour):**
1. Run `python analytics_tracker.py --report weekly`
2. Review performance (what worked/flopped?)
3. Adjust next week's content based on insights

---

### New Post Creation Workflow

1. **Choose template** from `CONTENT_TEMPLATES_LIBRARY.md`
2. **Customize** with your specific topic
3. **Generate AI variation** (optional): `content_generator.py`
4. **Create visual** in Canva (use brand guidelines)
5. **Proofread** carefully (typos kill credibility!)
6. **Check brand alignment** (voice, colors, hashtags)
7. **Schedule** via automation tool or manually
8. **Track performance** in analytics

## 🆘 Troubleshooting

### "I don't know what to post today"
→ Use `CONTENT_TEMPLATES_LIBRARY.md` templates  
→ Run `content_generator.py` for AI suggestions  
→ Check today's theme in `CONTENT_CALENDAR_SYSTEM.md`

### "This post doesn't sound like Kelly"
→ Review `SOCIAL_MEDIA_BRAND_GUIDELINES.md` voice section  
→ Check tone mode (Neutral/Fun/Wisdom)  
→ Read example posts in templates

### "Low engagement on posts"
→ Run `analytics_tracker.py` to see patterns  
→ Review `SOCIAL_MEDIA_STRATEGY.md` growth tactics  
→ A/B test different hooks, CTAs, posting times

### "Too time-consuming to post"
→ Batch create weekly content (see workflow above)  
→ Use automation tools (`post_scheduler.py`)  
→ Repurpose content (1 video → 10 posts)
