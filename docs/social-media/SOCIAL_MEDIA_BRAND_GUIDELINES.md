## 🎨 Visual Identity

### Color Palette

#### Primary Colors
```
Background: #0f0f13 (Deep Black)
Use: Main backgrounds, cards, dark mode

Text Primary: #f4f4f5 (Off-White)
Use: Headlines, body text, primary content

Kelly Blue: #2563eb (Primary Blue)
Use: CTAs, highlights, Kelly's brand color, links, buttons
Note: This is THE brand color. Kelly wears blue. Kelly IS blue.

Kelly Blue Light: #3b82f6
Use: Hover states, gradients, accents
```

#### Secondary Colors
```
Text Secondary: #a1a1aa (Warm Gray)
Use: Supporting text, timestamps, metadata

Card Background: #18181b (Charcoal)
Use: Post backgrounds, card elements

Border: #3f3f46 (Medium Gray)
Use: Dividers, borders, subtle separations

Success Green: #10b981
Use: Achievements, milestones, positive stats

Warning Yellow: #f59e0b
Use: Limited-time offers, important notices
```

#### Usage Rules
- **Never** use pure black (#000000) or pure white (#FFFFFF)
- Orange accent should appear in every post (logo, highlight, or CTA)
- Maintain 4.5:1 contrast ratio minimum (WCAG AA)
- Dark backgrounds preferred (brand consistency)

### Typography

#### Primary Font: SF Pro (Apple System Font)
**Use:** Body text, captions, UI elements
**Characteristics:** Clean, modern, highly legible
**Availability:** System font on iOS/Mac, download for other platforms

**Weights:**
- Regular (400) - Body text
- Medium (500) - Subheadings
- Semibold (600) - Emphasis
- Bold (700) - Headlines

#### Secondary Font: Times New Roman
**Use:** Headlines, quotes, wisdom moments
**Characteristics:** Classic, timeless, intellectual
**Why:** Contrasts modern UI with timeless learning

#### Font Pairings
```
Post Headline: Times New Roman Bold, 32-48pt
Body Text: SF Pro Regular, 14-16pt
Captions: SF Pro Regular, 12-14pt
CTAs: SF Pro Semibold, 16-18pt
```

#### Typography Rules
- **Line Height:** 1.5x for body, 1.2x for headlines
- **Letter Spacing:** Default (0) for body, -0.02em for headlines
- **Alignment:** Left-aligned for text blocks, center for headlines
- **Max Width:** 60-70 characters per line for readability

### Logo & Brand Mark

#### Primary Logo
**File:** `✨ Curious Kelly` (sparkles + wordmark)

**Variations:**
1. **Full Logo:** `✨ Curious Kelly` (use when space allows)
2. **Icon Only:** `✨` (profile pictures, favicons)
3. **Wordmark Only:** `Curious Kelly` (text-based contexts)

**Color Treatments:**
- Light Mode: `✨` in orange (#d97757), text in black
- Dark Mode: `✨` in orange (#d97757), text in white
- Monochrome: All white or all black (when color not possible)

**Minimum Sizes:**
- Full Logo: 120px width minimum
- Icon Only: 40px minimum
- Profile Pictures: Use icon only (✨) with orange background

#### Clear Space
Maintain minimum clear space of 1x the height of the starburst on all sides

#### Don'ts
- ❌ Don't rotate the logo
- ❌ Don't change the starburst to other symbols
- ❌ Don't add effects (shadows, gradients) to the logo
- ❌ Don't place on busy backgrounds (use solid color)

### Kelly's Avatar

#### Visual Style
- **Aesthetic:** Photorealistic digital human (NOT cartoon, NOT anime)
- **Age:** Late 20s to early 30s
- **Expression:** Warm, approachable, gentle smile
- **Build:** Athletic, capable, strong presence
- **Hair:** Long, wavy dark brown hair with subtle highlights
- **Eyes:** Dark brown, engaging, direct gaze

#### Wardrobe for Social Media
**Daily Lesson Context (Preferred for most social):**
- Clean, modern, professional attire
- Soft sweater or blouse
- Neutral colors (whites, grays, soft blues)
- Simple, minimal jewelry
- Setting: White studio background or subtle gradient

**Reinmaker Context (Game-related posts only):**
- Functional, futuristic armor
- Blue-gray steel palette
- Dark metallic fabrics
- Tech-integrated elements

#### Avatar Usage Guidelines
- **Always** show Kelly's face clearly (no heavy shadows)
- **Maintain** consistent character (same person across all posts)
- **Avoid** extreme expressions or poses
- **Context matters:** Use Daily Lesson Kelly for educational content, Reinmaker Kelly for game content

#### Prohibited Representations
- ❌ Kelly in controversial contexts (politics, religion)
- ❌ Kelly with weapons or violence (except game context)
- ❌ Kelly appearing drunk, disheveled, or unprofessional
- ❌ Kelly in inappropriate or suggestive situations

### Image Composition Guidelines

#### Social Media Post Dimensions

**Instagram:**
- Feed Post (Square): 1080 x 1080px
- Feed Post (Portrait): 1080 x 1350px
- Stories: 1080 x 1920px (9:16)
- Reels: 1080 x 1920px (9:16)

**Twitter/X:**
- Single Image: 1200 x 675px (16:9)
- In-Stream Photo: 1600 x 900px
- Header: 1500 x 500px

**Facebook:**
- Feed Image: 1200 x 630px
- Cover Photo: 820 x 312px

**YouTube:**
- Thumbnail: 1280 x 720px (16:9)
- Channel Art: 2560 x 1440px

**TikTok:**
- Video: 1080 x 1920px (9:16)

**LinkedIn:**
- Post Image: 1200 x 627px
- Cover Photo: 1584 x 396px

#### Composition Rules
1. **Rule of Thirds:** Place Kelly's eyes on upper third line
2. **Breathing Room:** Don't crop too tight, allow space around subject
3. **Text Overlay Zone:** Keep text in top or bottom third (never over Kelly's face)
4. **Safe Areas:** Keep important elements away from profile pictures/UI elements that overlap

#### Image Quality Standards
- **Resolution:** Minimum 2x native resolution (e.g., 2160 x 2160 for 1080px post)
- **File Size:** Under 10MB for images, under 100MB for videos
- **Format:** PNG for graphics with text, JPG for photos, MP4 for video

### Design Templates

#### Post Types & Visual Patterns

**1. Fact Post**
```
Layout: Kelly's avatar (left 40%) + Fact Text (right 60%)
Background: Dark gradient (#0f0f11 to #18181b)
Text: Large Times New Roman headline + SF Pro body
Accent: Orange highlight on key word
Logo: Bottom right corner
```

**2. Quote Post**
```
Layout: Centered text with Kelly's avatar subtle in background
Background: Solid dark (#0f0f11) with light vignette
Text: Large Times New Roman quote, serif for attribution
Accent: Orange quotation marks
Logo: Bottom center
```

**3. Lesson Highlight**
```
Layout: Full-screen Kelly teaching + text overlay bottom third
Background: Lesson context (studio, topic-related backdrop)
Text: Lesson title in bold + age range + duration
CTA: "Learn more" button in orange
Logo: Top left corner
```

**4. Community Post**
```
Layout: User-generated content + Kelly's reaction/comment
Background: User's image with dark overlay (50% opacity)
Text: Kelly's response in speech bubble
Accent: Orange border around user content
Logo: Bottom right corner
```

**5. Announcement Post**
```
Layout: Centered content, symmetrical
Background: Dark with subtle pattern or texture
Text: Large headline + supporting detail + CTA
Accent: Orange button or highlight
Logo: Top center
```

## 🎤 Voice & Tone Guide

### Kelly's Voice Characteristics

#### Core Traits (Always Present)
1. **Curious:** Asks questions, wonders "why?"
2. **Warm:** Kind, encouraging, never judgmental
3. **Intelligent:** Knowledgeable but not pretentious
4. **Enthusiastic:** Genuinely excited about learning
5. **Inclusive:** Everyone can learn, regardless of age or background

#### Voice Spectrum by Platform

| Platform | Formality Level | Emoji Use | Humor | Tech Jargon |
|----------|----------------|-----------|-------|-------------|
| Twitter/X | Medium | Moderate | High | Some |
| Instagram | Low (casual) | High | Medium | Minimal |
| YouTube | Medium-High | Low | Medium | Some |
| LinkedIn | High | Minimal | Low | Yes (education) |
| TikTok | Low (very casual) | High | High | Minimal |
| Discord | Low (conversational) | High | High | Community-specific |

---

### Three Voice Modes (Detailed)

#### 1. Neutral Mode 🎯

**When to Use:**
- LinkedIn posts
- Product announcements
- Educational research sharing
- Customer support responses
- Press releases

**Characteristics:**
- Professional but warm
- Data-driven statements
- Clear, informative language
- Minimal to no emojis
- Third-person or collective "we"

**Example - LinkedIn Post:**
> Curious Kelly PBC is excited to announce The Daily Lesson: a subscription-based learning platform that adapts to learners ages 2-102. 
>
> Our age-adaptive AI adjusts content complexity, vocabulary, and examples based on the learner's age, creating a personalized 8-minute daily lesson.
>
> Research shows that daily microlearning improves knowledge retention by 17% compared to weekly sessions. We've designed our platform around cognitive science principles to maximize learning impact.
>
> Launching December 17, 2025. Learn more at curiouskelly.com

**Vocabulary:**
- Use: "research," "data," "platform," "learners," "insights"
- Avoid: "OMG," "totally," "vibes," casual slang

---

#### 2. Fun Mode ✨

**When to Use:**
- Instagram Stories
- TikTok videos
- Twitter replies
- Community engagement
- Behind-the-scenes content

**Characteristics:**
- Playful, energetic
- Strategic emoji use (2-3 per post)
- Conversational, second-person "you"
- Exclamation points (1-2 per post)
- Questions to engage audience

**Example - Instagram Story:**
> Did you know octopuses have THREE hearts?! 🐙💙💙💙
>
> Two pump blood to the gills, one to the rest of the body. They also have blue blood (because of copper, not iron like us!)
>
> Nature is WILD, right? 🤯
>
> What animal fact blows your mind? Reply and I'll share the best ones! 👇

**Vocabulary:**
- Use: "totally," "wild," "cool," "awesome," "mind-blowing"
- Emojis: Relevant to content (animals, science symbols, celebratory)
- Punctuation: Exclamation points OK, but not excessive!!!

---

#### 3. Wisdom Mode 🌟

**When to Use:**
- End-of-lesson reflections
- Inspirational quotes
- Sunday/Monday motivational posts
- Milestone celebrations
- Long-form content conclusions

**Characteristics:**
- Reflective, thoughtful
- Poetic language
- Open-ended questions
- Timeless quality
- First-person "I" (Kelly's voice)

**Example - Twitter Thread Conclusion:**
> Curiosity isn't just about finding answers. It's about learning to live comfortably with questions.
>
> The most beautiful thing about knowledge? The more you learn, the more you realize how much you don't know.
>
> That's not discouraging. That's infinite possibility.
>
> What are you curious about today? 🌟

**Vocabulary:**
- Use: "wonder," "discover," "journey," "explore," "reflection"
- Avoid: Overly flowery language, clichés
- Punctuation: Periods, thoughtful pauses

### Writing Guidelines

#### Sentence Structure
- **Vary length:** Mix short punchy sentences with longer explanatory ones.
- **Active voice preferred:** "Kelly teaches you" not "You are taught by Kelly"
- **Second person:** "You'll learn" not "Users will learn"

#### Paragraph Length
- **Twitter:** 1-3 sentences per tweet (280 char limit)
- **Instagram Caption:** 3-5 sentences, line breaks for readability
- **YouTube Description:** Short intro (2-3 sentences) + timestamps + long description
- **LinkedIn:** 2-3 short paragraphs (10-15 lines total)

#### Hashtag Strategy
**Branded Hashtags (Always Include):**
- #CuriousKelly (main brand tag)
- #DailyLesson (product tag)
- #CuriousWithKelly (community tag)

**Topic Hashtags (2-3 per post):**
- #Science #STEM #History #Art #Learning

**Reach Hashtags (5-10 on Instagram):**
- #LifelongLearning #EdTech #Homeschool #Education #Teachers

**Hashtag Placement:**
- Twitter: In-line with text
- Instagram: End of caption or first comment
- TikTok: In caption (3-5 max)
- LinkedIn: End of post (3 max)

#### CTA (Call-to-Action) Guidelines
**Types of CTAs:**
1. **Engagement:** "What do you think?" "Tag someone who needs this"
2. **Traffic:** "Link in bio" "Learn more at curiouskelly.com"
3. **Conversion:** "Start learning" "Begin your journey" "Subscribe today"
4. **Community:** "Join our Discord" "Share your learning"

**CTA Frequency:**
- Every post should have one (and only one) primary CTA
- Engagement CTAs most common (80%)
- Conversion CTAs occasional (20%)

**IMPORTANT:** Never use "free" in CTAs. See `docs/brand/FORBIDDEN_WORD_FREE.md`.
- ❌ "Start your free trial" → ✅ "Start learning"
- ❌ "Try it free" → ✅ "Try a lesson"
- ❌ "Get started free" → ✅ "Begin your journey"

**CTA Placement:**
- End of caption (after value provided)
- On-screen text in videos (last 3 seconds)
- Button in link posts

## 📸 Photography & Video Guidelines

### Photography Style

#### Lighting
- **Preferred:** Soft, natural lighting (avoid harsh shadows)
- **Direction:** Front or 45-degree angle (Rembrandt lighting OK)
- **Color Temperature:** Warm (3500-4500K) for friendly feel

#### Backgrounds
- **Studio:** Clean white or subtle gradient (preferred for teaching content)
- **Contextual:** Topic-related backdrops (e.g., forest for nature lesson)
- **Depth:** Shallow depth of field (f/2.8-f/4) to isolate subject

#### Forbidden
- ❌ Busy, distracting backgrounds
- ❌ Direct flash (creates harsh shadows)
- ❌ Oversaturation or heavy filters
- ❌ Low-resolution or pixelated images

---

### Video Style

#### Technical Specs
- **Resolution:** Minimum 1080p (4K preferred for future-proofing)
- **Frame Rate:** 30fps (standard) or 60fps (smooth motion)
- **Aspect Ratio:** 16:9 (YouTube), 9:16 (TikTok/Stories), 1:1 (Instagram feed)
- **Bitrate:** Minimum 10Mbps for 1080p
- **Audio:** 48kHz, stereo, -14 LUFS (loudness)

#### Editing Style
- **Pace:** Dynamic but not frenetic (cut every 3-5 seconds)
- **Transitions:** Simple cuts or crossfades (no cheesy wipes)
- **Text Overlays:** SF Pro Bold, white with black stroke or dark background
- **Music:** Upbeat, royalty-free (Epidemic Sound, Artlist)
- **Volume:** Music at 20-30% volume when Kelly is speaking

#### Video Types

**Talking Head (Kelly Teaching):**
- Kelly centered or rule-of-thirds placement
- Eye contact with camera
- Subtitles/captions always (accessibility + sound-off viewing)
- B-roll every 5-10 seconds (illustrate concepts)

**Screen Recording (How-To):**
- 1080p screen capture
- Zoom into important areas
- Cursor highlights or animations
- Voiceover or on-screen text instructions

**Behind-the-Scenes:**
- Handheld OK (authentic feel)
- Natural lighting acceptable
- Show process, mistakes, iterations
- Casual tone

## 🚫 Don'ts: What to Avoid

### Visual Don'ts
- ❌ Comic Sans or novelty fonts
- ❌ Multiple font families in one post (max 2)
- ❌ Stretched or distorted images
- ❌ Watermarks from other platforms (crop out TikTok logo if reposting)
- ❌ Low-contrast text (ensure readability)
- ❌ Overuse of emojis in graphics (use in captions instead)

### Voice Don'ts
- ❌ Condescending language ("Obviously," "Everyone knows")
- ❌ Jargon without explanation (define technical terms)
- ❌ ALL CAPS (except for emphasis on 1-2 words)
- ❌ Overuse of ellipses... it feels... uncertain...
- ❌ Excessive hashtags (#stop #hashtagging #every #word)
- ❌ Engagement bait ("Double tap if you agree!!!")

### Content Don'ts
- ❌ Political takes (unless directly educational and neutral)
- ❌ Religious content (unless historical/cultural education)
- ❌ Controversial hot takes for engagement
- ❌ Competitor bashing (focus on our value)
- ❌ Fear-mongering or negativity
- ❌ False urgency ("LAST CHANCE!" when it's not)

## ♿ Accessibility Guidelines

### Text Accessibility
- **Minimum Font Size:** 14pt for body text
- **Contrast Ratio:** 4.5:1 for normal text, 3:1 for large text
- **Alt Text:** Every image must have descriptive alt text
- **CamelCase Hashtags:** #LikeTh is (screen readers can parse)

### Video Accessibility
- **Captions:** All videos must have accurate captions
- **Audio Description:** Describe visual elements when relevant
- **Flashing Content:** Avoid rapid flashing (seizure risk)
- **Text Duration:** On-screen text visible for 1 second per 3 words minimum

### Color Accessibility
- **Don't rely on color alone:** Use icons, text, patterns too
- **Test with Color Blind Simulator:** Ensure content works in grayscale
- **Provide alternatives:** If "red means error," also include an X icon

## ✅ Pre-Post Checklist

Before publishing any social media post, verify:

**Visual:**
- [ ] Logo present and correctly sized
- [ ] Colors match brand palette
- [ ] Text is legible at thumbnail size
- [ ] Image dimensions correct for platform
- [ ] Kelly's avatar (if present) is consistent

**Copy:**
- [ ] Spelling and grammar checked
- [ ] Voice/tone appropriate for platform
- [ ] One clear CTA included
- [ ] Hashtags relevant and correctly formatted
- [ ] No broken links

**Accessibility:**
- [ ] Alt text added
- [ ] Captions/subtitles on video
- [ ] Color contrast sufficient
- [ ] CamelCase hashtags

**Legal:**
- [ ] No copyrighted content used without permission
- [ ] Music is royalty-free or licensed
- [ ] User-generated content has permission to share
- [ ] Complies with platform policies
