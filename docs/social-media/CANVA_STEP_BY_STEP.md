# Canva: Step-by-Step Logo Creation (30 Minutes)
**For people who've never used Canva before**

---

## STEP 1: Set Up Canva (5 minutes)

1. **Go to:** https://canva.com
2. **Click:** "Sign up" (top right)
3. **Choose:** Sign up with Google/Email
4. **Select:** "For personal use" (free plan is fine)
5. **Skip** any tutorial prompts

✅ **You now have Canva open**

---

## STEP 2: Create Profile Picture (10 minutes)

### A. Start the Design
1. **Click:** "Create a design" (top right, purple button)
2. **Type:** "Instagram Post" in search
3. **Click:** "Instagram Post" template (1080×1080)

### B. Set Up Background
1. **Click:** Background color square (left sidebar)
2. **Paste color:** `#d97757` (press Enter)
3. **Result:** Orange background appears

### C. Add Kelly's Face
1. **Click:** "Uploads" (left sidebar)
2. **Click:** "Upload files"
3. **Navigate to:** `UI-TARS-desktop/public/assets/kelly/`
4. **Select:** `kelly-age-27-smile-front.png` (or any closeup)
5. **Click:** Open
6. **Wait:** Image appears in uploads
7. **Click:** The image to add to canvas
8. **Drag corners:** Make Kelly's face fill most of the square
9. **Position:** Center her face

### D. Add Sparkles
1. **Click:** "Elements" (left sidebar)
2. **Type:** "sparkles" in search
3. **Scroll** to find ✨ emoji or sparkle graphics
4. **Click:** One you like (it adds to canvas)
5. **Drag:** To top-right or bottom-right corner
6. **Resize:** Make it visible but not overwhelming
7. **Optional:** Click emoji → Change color to white if needed

### E. Download
1. **Click:** "Share" (top right)
2. **Click:** "Download"
3. **Select:** "PNG"
4. **Check:** "Transparent background" (if available)
5. **Click:** "Download"
6. **Rename file:** `curious-kelly-profile-pic.png`
7. **Move to:** `UI-TARS-desktop/public/assets/branding/`

✅ **DONE! Profile picture created.**

---

## STEP 3: Create Horizontal Logo (10 minutes)

### A. Start New Design
1. **Click:** "Create a design" (top right)
2. **Type:** "Logo" in search
3. **Click:** "Logo" template (500×500)
4. **Click:** "Resize" (top toolbar)
5. **Change to:** 3000 width × 1000 height
6. **Click:** "Copy & resize"

### B. Add Sparkles Symbol
1. **Click:** "Elements" (left sidebar)
2. **Type:** "sparkles emoji"
3. **Click:** ✨ emoji to add it
4. **Drag:** To left side
5. **Resize:** Make it medium-large
6. **Color:** Leave as emoji OR change to `#d97757`

### C. Add Text
1. **Click:** "Text" (left sidebar)
2. **Click:** "Add a heading"
3. **Type:** "Curious Kelly"
4. **Click:** Text to select it
5. **Top toolbar:**
   - Font: "Montserrat Bold" or "Raleway Bold" (SF Pro not in Canva)
   - Size: 200-250
   - Color: `#0f0f11`
6. **Drag:** Text next to sparkles
7. **Align:** Vertically center with sparkles

### D. Adjust Spacing
1. **Click + drag:** Sparkles and text to balance
2. **Leave space:** Between sparkles and text (~50px)
3. **Center:** Entire logo on canvas

### E. Download
1. **Click:** "Share" → "Download"
2. **Select:** "PNG"
3. **Check:** "Transparent background"
4. **Click:** "Download"
5. **Rename:** `curious-kelly-logo-horizontal.png`
6. **Move to:** `UI-TARS-desktop/public/assets/branding/`

✅ **DONE! Logo created.**

---

## STEP 4: Create Twitter Header (5 minutes)

### A. Start New Design
1. **Click:** "Create a design"
2. **Type:** "Twitter header"
3. **Click:** "Twitter Header" (1500×500)

### B. Add Background
1. **Click:** "Elements" (left sidebar)
2. **Type:** "gradient background"
3. **Find:** A dark gradient you like
4. **Click:** To add as background
5. **Adjust:** Colors to dark charcoal if needed

### C. Add Kelly
1. **Click:** "Uploads"
2. **Select:** Kelly image (upper body pose)
3. **Drag:** To left side of header
4. **Resize:** To fit nicely

### D. Add Text
1. **Click:** "Text" → "Add a heading"
2. **Type:** 
   ```
   365 days of learning
   with your AI teacher ✨
   ```
3. **Font:** Montserrat Bold
4. **Size:** 80-100
5. **Color:** White (#ffffff)
6. **Position:** Right side of Kelly
7. **Add text shadow:** Effects → Shadow → Glow

### E. Download
1. **Share → Download → PNG**
2. **Rename:** `twitter-header.png`
3. **Move to:** `public/assets/branding/`

✅ **DONE! Twitter header created.**

## TROUBLESHOOTING

**"I can't find Kelly's face images"**
→ Check these folders:
- `UI-TARS-desktop/public/assets/kelly/`
- `UI-TARS-desktop/kelly_pack/output/`
→ Or skip Kelly and just use ✨ + text for now

**"Canva wants me to upgrade to Pro"**
→ Some elements require Pro
→ Use free alternatives or skip fancy effects
→ Basic logos work fine!

**"The sparkles emoji looks weird"**
→ Search "star icon" or "sparkle graphic" instead
→ Use a vector sparkle shape

**"I'm not a designer, this looks bad"**
→ That's OK! It's a temporary version
→ You can improve later
→ Good enough to create social accounts = WIN
