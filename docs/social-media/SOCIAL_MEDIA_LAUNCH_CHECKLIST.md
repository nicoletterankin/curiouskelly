## 🚨 Crisis Management Checklist

### If Negative Feedback / Complaint:
1. [ ] Acknowledge within 2 hours
2. [ ] Empathize ("We understand your concern")
3. [ ] Take conversation private (DM / email)
4. [ ] Resolve issue
5. [ ] Follow up publicly ("Issue resolved, thank you!")

### If Technical Outage:
1. [ ] Post acknowledgment on all platforms immediately
2. [ ] Provide status updates every hour
3. [ ] Communicate expected resolution time
4. [ ] Offer compensation (extend free trial, discount)
5. [ ] Post-mortem transparency

### If Viral Negative Post:
1. [ ] Assess validity (is criticism fair?)
2. [ ] Craft official response (CEO or spokesperson)
3. [ ] Post on all platforms (transparency)
4. [ ] Address in Discord #announcements
5. [ ] Learn and improve (actionable takeaways)
