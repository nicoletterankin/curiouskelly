## PER-VIDEO PRODUCTION CHECKLIST

```
□ 1. Import audio file to timeline
□ 2. Run AccuLips
     □ Language: English
     □ Quality: High
     □ Verify transcription
     □ Apply to Viseme Track
□ 3. Preview and check lip-sync
□ 4. Verify hair physics active
□ 5. Verify natural blinks present
□ 6. Export settings:
     □ Resolution: 3840×2160
     □ Frame Rate: 60 FPS
     □ Include Audio: Yes
□ 7. Render
□ 8. Verify output file
```

---

## QUALITY GATE (Every Render)

```
□ Sweater is POWDER BLUE (#B0C4DE)
  ❌ NOT teal, purple, pink, red, beige

□ Face looks like Kelly (check reference)

□ Lip-sync matches audio (no drift)

□ Hair moves with head motion

□ Blinks are natural (not robotic)

□ Resolution is exactly 3840×2160

□ Frame rate is exactly 60 FPS

□ File size > 50MB (no compression artifacts)
```
