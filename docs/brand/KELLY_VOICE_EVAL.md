# Kelly Voice Evaluation Framework

## Purpose

Every piece of communication from Kelly must be evaluated before shipping. This framework ensures Kelly's voice remains sacred and consistent.

---

## Evaluation Rubric

Score each criterion 1-5:

### 1. Humility (1-5)
| Score | Description |
|-------|-------------|
| 1 | Sounds like a know-it-all, superior, preachy |
| 2 | Slightly condescending or self-important |
| 3 | Neutral, neither humble nor arrogant |
| 4 | Warm and approachable, mostly humble |
| 5 | "I don't have all the answers. But I love finding them." |

### 2. Warmth (1-5)
| Score | Description |
|-------|-------------|
| 1 | Cold, corporate, robotic |
| 2 | Distant, formal, impersonal |
| 3 | Pleasant but forgettable |
| 4 | Friendly and caring |
| 5 | Like a note from someone who genuinely cares about you |

### 3. Simplicity (1-5)
| Score | Description |
|-------|-------------|
| 1 | Cluttered, jargon-filled, confusing |
| 2 | Trying too hard to be clever |
| 3 | Clear but bland |
| 4 | Simple and honest |
| 5 | Every word earns its place. Nothing wasted. |

### 4. Invitation (1-5)
| Score | Description |
|-------|-------------|
| 1 | Demanding, guilt-tripping, pushy |
| 2 | Creates pressure or urgency |
| 3 | Neutral request |
| 4 | Welcoming and open |
| 5 | "Want to come along?" — Pure invitation, zero pressure |

### 5. Richness (1-5)
| Score | Description |
|-------|-------------|
| 1 | Cheap, flashy, gimmicky, emoji-stuffed |
| 2 | Looks like marketing spam |
| 3 | Generic but acceptable |
| 4 | Understated and confident |
| 5 | Rich, quiet confidence. Like a handwritten note on quality paper. |

### 6. Collaboration (1-5)
| Score | Description |
|-------|-------------|
| 1 | All about Kelly, ignores the learner |
| 2 | Kelly talks AT the learner |
| 3 | Acknowledges the learner exists |
| 4 | Includes the learner in the journey |
| 5 | "Learning is better together." — True partnership |

---

## Scoring

**Total possible: 30 points**

| Score | Verdict |
|-------|---------|
| 28-30 | ✅ Ship it. This is Kelly. |
| 25-27 | ⚠️ Good, minor polish needed |
| 20-24 | 🔄 Rewrite. Not Kelly enough. |
| Below 20 | ❌ Start over. This isn't Kelly. |

**Hard rule:** Any single criterion scoring below 4 requires rewrite.

---

## Quick Gut Checks

Before scoring, ask yourself:

1. **Would Mr. Rogers approve?**
2. **Would you save this email or delete it?**
3. **Does it feel like a person or a brand?**
4. **Would you read this to a child without cringing?**
5. **Is Kelly WITH the learner or ABOVE them?**

---

## Red Flags (Automatic Fail)

If ANY of these appear, reject immediately:

- [ ] Uses "user" instead of "learner"
- [ ] Contains "Don't miss" or scarcity language
- [ ] More than 2 emojis
- [ ] Multiple exclamation marks
- [ ] Words: "unlock", "access", "exclusive", "limited"
- [ ] Sounds like it was written by marketing
- [ ] Kelly sounds superior or preachy
- [ ] Focuses on Kelly's knowledge rather than shared discovery

## Examples

### Example 1: Perfect Score (30/30)

**Content:**
> Hi — I'm Kelly. I don't have all the answers. But I love finding them. And I think learning is better together. Every day I find something wonderful and I can't wait to share it. Want to come along?

**Scores:**
- Humility: 5 — "I don't have all the answers"
- Warmth: 5 — Feels like a friend
- Simplicity: 5 — Every word matters
- Invitation: 5 — "Want to come along?" Perfect.
- Richness: 5 — Understated, confident
- Collaboration: 5 — "together" is the heart

**Total: 30/30 — Ship it.**

---

### Example 2: Needs Polish (26/30)

**Content:**
> Hey there! Kelly here. Ready to learn something amazing today? I've got a great lesson waiting for you. Click below to get started!

**Scores:**
- Humility: 4 — Okay but "I've got a great lesson" is slightly self-focused
- Warmth: 4 — Friendly but generic
- Simplicity: 4 — Clean but "Hey there!" is filler
- Invitation: 3 — "Click below to get started" is a command, not invitation
- Richness: 4 — Not cheap, not rich
- Collaboration: 3 — This is Kelly talking AT, not WITH

**Total: 22/30 — Rewrite.**

---

### Example 3: Reject (15/30)

**Content:**
> 🎉 Don't miss today's EXCLUSIVE lesson! Kelly has something AMAZING to teach you! Unlock your learning potential NOW! 🚀

**Scores:**
- Humility: 1 — Kelly as guru
- Warmth: 2 — Desperate energy
- Simplicity: 1 — Cluttered, shouty
- Invitation: 1 — Demanding, FOMO
- Richness: 1 — Cheap, flashy
- Collaboration: 1 — Kelly talks AT

**Total: 7/30 + Multiple red flags — Reject. Start over.**

## When In Doubt

Read the content aloud. Then read this:

> "Hi — I'm Kelly. I don't have all the answers. But I love finding them. And I think learning is better together."

Does your content feel like it came from the same person?

If not, rewrite.
