## 🎬 HeyGen Workflow (Single Avatar Strategy)

Since we only have ONE real Kelly, we use ONE HeyGen Photo Avatar for all archetypes.

**The archetype differentiation comes from:**
1. **Voice/Script** — ElevenLabs Kelly voice with archetype-specific language
2. **HeyGen motion** — AI generates natural movement from audio
3. **NOT from different images** — Kelly looks the same, speaks differently

### Upload to HeyGen:
1. Go to app.heygen.com → Avatars → Create new
2. Upload: `head and shoulders without chair.png`
3. Wait for processing ("Review new look" → complete)
4. Copy Avatar ID for API use
