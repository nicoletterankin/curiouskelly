## 📋 RENDER CHECKLIST

### iClone/CC5 Setup

- [ ] Load final CC5 Kelly model
- [ ] Set up studio lighting preset (save for reuse)
- [ ] Position director's chair prop
- [ ] Create camera bookmarks for each shot type:
  - Profile (head/shoulders)
  - Hero (upper body in chair)
  - Teaching poses (mid-body)
  - Expressions (face closeup)
- [ ] Set render quality to maximum

### Render Settings

| Setting | Value |
|---------|-------|
| Resolution | 4K master, downscale as needed |
| Anti-aliasing | 16x MSAA |
| Ambient Occlusion | ON |
| Global Illumination | ON |
| Background | Transparent (PNG alpha) |
| Format | PNG (lossless) → JPEG where needed |

### Quality Checks

For each render, verify:
- [ ] Hair looks natural (no clipping)
- [ ] Skin texture is smooth but realistic
- [ ] Eyes have catchlights
- [ ] Clothing has no physics glitches
- [ ] Expression matches intent
- [ ] Background is clean/transparent
- [ ] Resolution is correct
