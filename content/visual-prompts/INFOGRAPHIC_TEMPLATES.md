## 🏆 THE GOLD STANDARD: Day 5 Prompt

This is the prompt that created our best infographic ever:

```
Educational infographic: Split-scene comparison showing sound transmission 
through different media. 

LEFT SIDE: Deep underwater scene with a majestic humpback whale emitting 
visible concentric sound waves that travel far through crystal-clear blue 
water, arrows showing 'Sound travels faster' with speed label '1500 m/s', 
text overlay 'Communicating Whale'. 

RIGHT SIDE: Golden hour scene of railroad tracks extending to horizon, 
steam train approaching in distance, young woman with brown hair standing 
near tracks cupping hand to ear listening, sound wave visualization 
traveling through metal rails, text overlay 'Railroad Tracks' and 'Hear 
the train coming'. 

Seamless color transition from cool ocean blue to warm sunset orange. 
Header text: 'Sound Travels Faster in Water & Solids'. 

Photorealistic cinematic style, 8K resolution, educational diagram 
aesthetic with clean typography, dramatic lighting.
```

### Why It Works:
1. **Split scene** creates instant visual comparison
2. **Relatable subjects** (whale, train) everyone recognizes
3. **Human POV** (girl listening) creates learner identification
4. **Data callout** (1500 m/s) provides scientific precision
5. **Color story** (blue→orange) guides eye and creates mood
6. **Clear text hierarchy** (header, labels, callouts)

- Scene: [INITIAL CONDITION]

- Label: "Before: [STATE]"

AFTER STATE (right side or bottom):
- Scene: [FINAL CONDITION]
- Key visual: [WHAT IT LOOKS LIKE AFTER]

- Label: "After: [STATE]"

Header text: "[TRANSFORMATION DESCRIBED - 8 WORDS MAX]"

```

## 📏 TYPOGRAPHY GUIDELINES

### Header Text (on infographics)
- **Font style:** Bold sans-serif
- **Size:** 72-96pt for 4K, 36-48pt for 1080p
- **Color:** White with subtle drop shadow
- **Position:** Top center or top-left
- **Max length:** 8 words

### Labels (parts/callouts)
- **Font style:** Medium sans-serif
- **Size:** 36-48pt for 4K, 18-24pt for 1080p
- **Color:** White on dark backgrounds, dark on light
- **Connected by:** Clean 2px lines

### Data Callouts (statistics)
- **Font style:** Bold, slightly larger
- **Size:** 48-72pt for 4K
- **Color:** Accent color for emphasis
- **Position:** Near relevant visual element

### Option Card Text
- **Font style:** Bold sans-serif
- **Size:** 24-32pt
- **Color:** White on dark band
- **Position:** Bottom center

## ✅ GENERATION CHECKLIST

Before generating any infographic:

- [ ] Does this teach the core concept visually?
- [ ] Would a 6-year-old understand the main idea?
- [ ] Is there a human/relatable element?
- [ ] Is text minimal and impactful?
- [ ] Does color palette match the topic mood?
- [ ] Are comparison elements clearly different?
- [ ] Is there visual hierarchy (eye knows where to go)?
- [ ] Does it work at thumbnail size?

After generation QA:

- [ ] Text is readable on mobile
- [ ] No spelling errors in overlays
- [ ] Colors aren't muddy or washed out
- [ ] Subject is clear, not cluttered
- [ ] Scientific accuracy verified
- [ ] Consistent with Kelly visual brand
- [ ] Exports at correct resolution

professional photography, ultra detailed

### To increase clarity:
```
, clean composition, clear visual hierarchy, uncluttered,
educational diagram aesthetic, high contrast
```

### To add warmth:
```
, warm golden lighting, sunset tones, inviting atmosphere,
friendly educational style
```

### To add drama:
```
, dramatic lighting, strong shadows, cinematic depth,
impactful visual, eye-catching composition
```

### Negative prompt (always include):
```
Negative: blurry, low quality, distorted text, misspelled words,
cluttered, confusing, cartoon, anime, illustration style,
watermark, logo, text errors
