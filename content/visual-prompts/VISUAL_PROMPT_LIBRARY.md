## 🌟 VISUAL PHILOSOPHY

Every image in Curious Kelly must **TEACH**, not just entertain. Each visual decision serves a pedagogical purpose:

1. **Backgrounds create context** - The environment reinforces the lesson's theme
2. **Kelly embodies understanding** - Her pose and expression show HOW to engage with the material
3. **Props are visual aids** - Objects that make abstract concepts concrete
4. **Colors carry meaning** - Emotional and cognitive associations
5. **Composition guides attention** - Where the eye goes, learning follows

## 📐 TECHNICAL SPECIFICATIONS

### Image Dimensions
```
Primary: 3840 × 2160 px (4K UHD, 16:9)
Fallback: 1920 × 1080 px (Full HD)
Mobile:  1080 × 1920 px (9:16 portrait)
Thumb:    640 × 360 px (preview)
```

### File Format
- **Format:** PNG with transparency (for Kelly composites)
- **Compression:** Lossless for masters, optimized PNG for web
- **Color space:** sRGB
- **Bit depth:** 24-bit (8-bit per channel)

### Naming Convention
```
/kelly/lessons/{DAY_PADDED}/lesson-{DAY}-{TYPE}.png

Examples:
/kelly/lessons/001/lesson-1-hero.png
/kelly/lessons/001/lesson-1-prop.png
/kelly/lessons/001/lesson-1-guide-point.png
/kelly/lessons/001/lesson-1-reaction.png
/kelly/lessons/001/lesson-1-bg.png
```
