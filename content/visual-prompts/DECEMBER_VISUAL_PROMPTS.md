## 🔧 GENERATION WORKFLOW

1. **Use Midjourney, DALL-E 3, or Flux** for image generation
2. **Upscale to 4K** (3840x2160 for backgrounds, appropriate resolution for Kelly images)
3. **Kelly images need transparent backgrounds** - use background removal
4. **Name files exactly as specified** for the visual system to load them automatically
5. **Test each day** by navigating to `/learn?day=340` etc.

## ⏱️ TIME ESTIMATE

- 26 days × 5 images = 130 images
- ~5-10 minutes per image with AI generation
- Total: 10-20 hours of generation work
- Can be parallelized across multiple generators
