Build with Kelly

Integrate Curious Kelly's 365-day learning curriculum into your apps. Access daily lessons, personalized content atoms, and user progress tracking.

● REST API v1

Authentication

The Curious Kelly API uses Supabase for authentication. All requests require a valid API key passed in the request headers.

API Keys

Your API key is available in your account dashboard after subscribing to an enterprise plan.

ℹ️

Public vs Private Keys: Use the public (anon) key for client-side requests. The private (service) key should only be used server-side.

Headers

// Required headers for all requests
apikey: your-supabase-anon-key
Authorization: Bearer your-supabase-anon-key
Content-Type: application/json

Base URL

https://your-project.supabase.co/rest/v1

Rate Limits

To ensure fair usage and system stability, all API endpoints are rate limited.

Plan Requests/min Daily Limit
Starter 10 1,000
Scholar ($12/mo) 60 10,000
Enterprise 300 Unlimited

Rate limit headers are included in all responses:

X-RateLimit-Limit: 60
X-RateLimit-Remaining: 58
X-RateLimit-Reset: 1701792000

Lessons

Access the complete 365-day curriculum. Each day features a unique topic with universal truths and personalized content atoms.

GET /core_lessons

Retrieve all lessons or filter by day number.

Query Parameters

ParameterTypeDescription
day_number integer Filter by specific day (1-365)
select string Fields to return (PostgREST syntax)

Example Request

curl 'https://your-project.supabase.co/rest/v1/core_lessons?day_number=eq.1&select=id,day_number,topic,universal_truth' \
  -H "apikey: YOUR_API_KEY" \
  -H "Authorization: Bearer YOUR_API_KEY"

Response

[
  {
    "id": "9f8af9c5-66d6-40a0-a10c-b95a7940d25c",
    "day_number": 1,
    "topic": "Water",
    "universal_truth": "Water transforms between solid, liquid, and gas..."
  }
]
GET /core_lessons?day_number=eq.{day}

Get a specific day's lesson with full content.

// JavaScript example
const { data, error } = await supabase
  .from('core_lessons')
  .select('id, day_number, topic, universal_truth, marketing_headline')
  .eq('day_number', 1)
  .single();

Lesson Atoms

Lesson atoms are the building blocks of personalized learning. Each lesson has 60 atoms across different archetypes and phases.

🧬

What are atoms? Each atom contains a script tailored to a specific learner archetype (The Survivor, The Explorer, etc.) and learning phase (Fact1, Fact2, Fact3).

GET /lesson_atoms?core_lesson_id=eq.{lesson_id}

Get all atoms for a specific lesson.

const { data } = await supabase
  .from('lesson_atoms')
  .select('archetype, phase, content')
  .eq('core_lesson_id', lessonId);

Atom Structure

{
  "archetype": "The Survivor",
  "phase": "Fact1",
  "content": {
    "script": "Water is essential for survival...",
    "options": ["Tell me more", "Why?", "Next fact"],
    "responses": { ... }
  }
}

SDKs

Use our official SDKs for faster integration.

JavaScript / TypeScript

// Install the Supabase client
npm install @supabase/supabase-js

// Initialize
import { createClient } from '@supabase/supabase-js'

const supabase = createClient(
  'https://your-project.supabase.co',
  'your-anon-key'
)

// Get today's lesson
const today = new Date()
const dayOfYear = Math.floor((today - new Date(today.getFullYear(), 0, 0)) / 86400000)

const { data: lesson } = await supabase
  .from('core_lessons')
  .select('*')
  .eq('day_number', dayOfYear)
  .single()

Python

# Install the Supabase client
pip install supabase

# Initialize
from supabase import create_client

supabase = create_client(
    'https://your-project.supabase.co',
    'your-anon-key'
)

# Get today's lesson
from datetime import datetime
day_of_year = datetime.now().timetuple().tm_yday

lesson = supabase.table('core_lessons') \
    .select('*') \
    .eq('day_number', day_of_year) \
    .single() \
    .execute()
