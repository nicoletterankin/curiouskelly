Accessibility

Curious Kelly is committed to making daily learning accessible to everyone. We believe curiosity knows no bounds, and neither should access to knowledge.

Last updated: December 5, 2025

Our Commitment

At Lesson of the Day PBC, we are committed to ensuring digital accessibility for people with disabilities. We continually improve the user experience for everyone and apply the relevant accessibility standards.

We aim to conform to the Web Content Accessibility Guidelines (WCAG) 2.1 at Level AA. These guidelines explain how to make web content more accessible for people with disabilities and more user-friendly for everyone.

Accessibility Features

Curious Kelly includes the following accessibility features:

⌨️

Keyboard Navigation

Full keyboard access to all features and content.

🔊

Audio Lessons

All lessons are available as spoken audio narration.

📝

Text Transcripts

Written transcripts available for all audio content.

🎨

High Contrast

Dark mode design with sufficient color contrast ratios.

📱

Responsive Design

Works on all device sizes and orientations.

🔤

Scalable Text

Text can be resized up to 200% without loss of functionality.

Conformance Status

The Web Content Accessibility Guidelines (WCAG) defines requirements for designers and developers to improve accessibility for people with disabilities.

● Partially Conformant to WCAG 2.1 Level AA

Partially conformant means that some parts of the content do not fully conform to the accessibility standard. We are actively working to achieve full conformance.

What We're Working On

  • Improving screen reader compatibility for interactive lesson elements
  • Adding closed captions to video content
  • Enhancing focus indicators throughout the application
  • Implementing ARIA live regions for dynamic content updates
  • Providing alternative text for all decorative images

Assistive Technologies

Curious Kelly is designed to be compatible with the following assistive technologies:

  • Screen readers: VoiceOver (macOS/iOS), NVDA, JAWS
  • Voice control: Dragon NaturallySpeaking, Voice Control (iOS/macOS)
  • Magnification: ZoomText, built-in OS magnifiers
  • Switch access: Compatible with switch navigation devices

Known Limitations

Despite our best efforts, there may be some limitations. Below is a description of known limitations and potential solutions:

  • Interactive avatar animations: Kelly's animated expressions may not be fully described by screen readers. We provide equivalent text descriptions.
  • Third-party content: Some embedded content from third parties may not meet accessibility standards. We work with partners to improve this.
  • PDF documents: Some downloadable resources may not be fully accessible. Contact us for alternative formats.

Technical Specifications

Curious Kelly relies on the following technologies to work with the particular combination of web browser and any assistive technologies or plugins installed on your computer:

  • HTML5
  • CSS3
  • JavaScript
  • WAI-ARIA

These technologies are relied upon for conformance with the accessibility standards used.

Assessment Approach

Lesson of the Day PBC assessed the accessibility of Curious Kelly by the following approaches:

  • Self-evaluation using automated testing tools (axe, WAVE, Lighthouse)
  • Manual testing with keyboard navigation
  • Testing with screen readers (VoiceOver, NVDA)
  • User testing with people with disabilities (ongoing)
