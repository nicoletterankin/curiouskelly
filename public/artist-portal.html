Production Pipeline

From Audio to Film-Quality Video

Our end-to-end workflow using tools we already own.

Audio Generation

ElevenLabs API

Kelly's voice is generated from lesson scripts using our trained ElevenLabs voice model. Each phrase is rendered at 48kHz.

// Voice ID: Kelly (trained)
voice_settings: {
  stability: 0.5,
  similarity_boost: 0.85,
  style: 0.2
}

Import to iClone

iClone 8.62

Audio is imported to the timeline. Kelly's CC5 character is loaded in the Director's Chair scene.

Lip-Sync Generation

AccuLips Plugin

AccuLips analyzes phonemes and generates precise viseme animation. 99% accuracy with natural coarticulation.

Settings:
  Language: English (US)
  Quality: High
  Lip Strength: 1.0
  Jaw Strength: 0.8

Expression Layer

AccuFACE Plugin

Brow, eye, and head movements are layered on top of lip-sync for full facial animation.

4K/60fps Render

iClone Renderer + RTX 5090

Final render at 3840×2160, 60fps with full hair physics, Digital Human Shader, and studio lighting.

Export Settings:
  Resolution: 3840×2160 (4K UHD)
  Frame Rate: 60 FPS
  Codec: H.264 High Profile
  Bitrate: 50 Mbps
  Hair Physics: Enabled

Quality Gate

Automated + Manual QA

Every video passes face audit, sweater color check, and lip-sync validation before publishing.
