## Usage Guide

### For Attorney

1. Review `CONFIDENTIAL-STRATEGY.md` for full context
2. Use `GSA-PROPOSAL.md` as basis for formal outreach
3. Customize language as appropriate for legal context
4. Never share full strategy document with GSA

### For Foundation Meetings

1. Sign NDA before any presentation
2. Use `FOUNDATION-PITCH.md` for full vision
3. Reference `FINANCIAL-MODEL.xlsx` for budget details
4. Do not share digital copies unless necessary

### For GSA

1. Only share `GSA-PROPOSAL.md` (via attorney)
2. Customize with attorney letterhead
3. Remove or redact internal notes
4. Present as serious, funded buyer

### For Public (Later)

1. Use `LESSON-OF-THE-DAY-HQ.md` only after acquisition closes
2. Review with PR counsel before release
3. May need further editing for public consumption
