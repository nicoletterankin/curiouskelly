## Architecture: Three-Tier Video System

### Tier 1: Pre-rendered Library (Highest Quality)
- Pre-generate videos for all 365 lessons
- 4K resolution, professionally polished
- Stored in Supabase/R2 for instant playback
- **Zero generation latency**

### Tier 2: Real-time Flux + Wav2Lip (Medium Quality)
- For dynamic/custom content
- Generate Kelly frames with LoRA
- Apply lip-sync in real-time
- ~30 seconds generation time

### Tier 3: Unity 3D Fallback (Low Latency)
- For interactive conversations
- Real-time viseme-based animation
- WebGL delivery

## Implementation Plan

### PHASE 1: Wav2Lip HD with Kelly LoRA (This Week)

The key insight: **Use Flux + Kelly LoRA to generate the base frame, then apply Wav2Lip HD for accurate lip-sync.**

```
Audio (ElevenLabs) ─┐
                    ├─► Wav2Lip HD ─► 4K Upscale ─► Final Video
Kelly Image (LoRA) ─┘
```

Wav2Lip is **much more accurate** than SadTalker for lip-sync (95%+ accuracy).

### PHASE 2: Frame-by-Frame Generation (Best Quality)

Generate each frame using Flux + LoRA with mouth position conditioning:

```
1. Extract phonemes from audio → [AH, EE, OH, MM, ...]
2. Map phonemes to mouth shapes → [open, smile, round, closed, ...]
3. Generate each frame with Flux + LoRA + mouth prompt
4. Compile frames into video
```

This produces **perfect Kelly** because every frame is generated by YOUR trained model.

### PHASE 3: Pre-render Library (Production)

For the 365 daily lessons:
```
- 5 phases × 365 days = 1,825 video clips
- Average 30 seconds each
- Pre-render overnight in batches
- Store in CDN for instant playback
```
